# IC autolab

Work from this skill's containing repository, not a similarly named sibling or
an old absolute path in an archived JSON file. Read `AGENTS.md` and
`research/ic_candidate_tournament_20260915/AUTOLAB.md`. That directory contains
the existing tournament, independent certificate checker, portfolio selector,
portable development driver, and frozen historical evidence. Extend these;
do not create a parallel scoreboard or redefine historical protocols.

## Begin or resume

Run `python3 research/ic_candidate_tournament_20260915/autolab.py doctor`.
Inspect the latest local round's contract, source identity, summary and failures.
Archived winners must be restored and identified by their candidate's
`source_directory` and configuration, not assumed to be `round/source`.
Use an isolated checkout when the working tree contains other work.

The development screen works on macOS and Linux. The promotion tournament
requires Linux amd64 and Valgrind 3.22.0. Never put native seconds into an
instruction-count field. Missing tools mean an operational limitation, not an
algorithmic failure. The separate Crypto Autoresearcher Coordinator harness is
not required by this repository-local runner.

## Quality and accounting first

Read [the measurement contract](../../../research/ic_candidate_tournament_20260915/MEASUREMENT.md) before a new comparison. Canonical curve/candidate/workload/run records and the independent usable-base census are implemented in `identity.py`; `measurement.py` leaves incomplete scientific totals unknown. The restored optimized producers pass fixed-vector scientific admission, public-point input and single-target native interval controls, including independent transport replay. Reusable IC and rho preparation stays outside the online interval; cold costs remain separate. Both existing drivers now require canonical admission and retain success/failure records plus single-target online tables. The [archived reference panel](../../../research/ic_candidate_tournament_20260915/goal_20260924/reference-qualification/README.md) has executed; use its audited source/settings selection and preserve the separate cold/online rho references. The [goal checkpoint](../../../research/ic_candidate_tournament_20260915/goal_20260924/STATUS.md) still requires cross-campaign target exclusions and a frozen familywise confirmation rule before an improvement round. Exact replay of that historical floating-summary bundle uses Linux/Python 3.12; its documented one-ULP macOS differences do not justify rewriting sealed evidence. Closed historical dump intervals are not eleven exclusive scientific phases. Preserve old sealed evaluators for historical replay.

Before a rho comparison, inspect the actual reference path and run its release
tests for reference/packed agreement, fruitless-cycle escape, charge closure,
and birthday-scale walk counts. Screen rho walk widths on the same development
targets as IC; lock a strong measured reference before held-out confirmation.
If a faster compatible implementation is found, update and remeasure the
reference. Do not certify a reference as globally optimal. Preserve its curve,
subgroup, automorphisms, hardware, thread count, memory, setup and target count.

Require the checker to verify every group relation, scalar-field rank, factor
log and actual per-target descent relation. A valid final scalar alone does not
prove the candidate used IC. Keep degenerate direct collisions out of IC claims.
All setup, unsuccessful attempts, encoding, solving, lifting, relation processing,
linear algebra, descent, verification and reporting belong to the cold job.
GF(2) elimination inside a Boolean Gröbner/SAT solver is distinct from relation
linear algebra modulo the prime subgroup order. Missing costs remain null.

Review algorithm kernels as well as the harness. Cross-check replacements on
the same inputs against independent/reference arithmetic. For algebra changes,
run the applicable frozen algebra regression and fresh holdouts in addition to
complete solves. A correct but deliberately slow baseline cannot substantiate a
best-known comparison. External SAT/GPU tools need pinned executables, tested
adapters and child/device accounting; unsupported engines are not results.

## Iterate without discarding useful alternatives

Use `autolab.py propose --panel implementation|algebra|factor-base --out FILE`.
For algebra panels pass `--base-config FILE` with a compatible linear base and
summand count; begin with the examples in `AUTOLAB.md`. For support-changing
experiments declare `--comparison-kind factor-base-policy`. Preserve identical
public ECDLP targets across arms and stable support inside each arm; record
actual base size, orbit columns and rank, including sampler overshoot.

Run bounded development screens with a fresh `--seed`, candidate registry and
new output directory. Use the frozen evaluator printed in the command examples
for resumption and audit. Retain failed, timed-out, rejected and regressing arms.
The native screen is diagnostic and always sets `promotion_eligible=false`.

Keep a portfolio: total-cost leaders, alternatives on the Pareto frontier,
different solver/base families, cell specialists, and predeclared exploration
slots. Use development evidence only. `autolab.py recombine` builds explicit
combinations of disjoint configuration changes; source combinations need their
own builds. Measure each combination as a complete algorithm. Never sum cheap
phases from different runs. Include some initially slower mechanisms: interaction
can reverse their ranking. This mitigates local search traps; it does not prove
a global optimum. Track trials across rounds to avoid rediscovering the same
configuration and count a new family/size/resource regime as a separate panel.

## Confirm, report, continue

Use `tournament.py prepare` for the calibrated instruction tournament and
`--selection-width` / `--exploration-slots` to freeze its portfolio budget.
Selection locks one challenger; confirmation and replay cannot be used to
retune it. Preserve final failures. Subsequent tuning requires new held-out
targets and a new frozen protocol, never a retry until success.

Audit with the round's frozen evaluator. Report the full measured workload,
baseline quality limits, correctness/completion counts, exclusive costs,
uncertainty, rho ratio, applicable floor and engineering/accounting classification.
Update the research note and canonical scoreboard from stored measurements in
the same change. Do not call a small-field or single-host win the globally fastest
IC implementation or an ECC2K-130 speedup.

Continue while the user's authorized budget allows useful work; checkpoint the
exact artifacts, open defects and next command. A request to iterate authorizes
bounded local rounds, not an indefinite service or new paid infrastructure.
