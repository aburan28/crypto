# Mathematical contract

## Discriminants and scope

For a short Weierstrass model in characteristic other than 2 or 3,
`Delta_curve = -16(4A^3 + 27B^2)` certifies nonsingularity.
This is distinct from the CM discriminants below.

For an ordinary elliptic curve over F_q, put `t = q + 1 - #E(F_q)`.
Frobenius satisfies `pi^2 - [t]pi + [q] = 0` and
`Delta_pi = t^2 - 4q`. The quadratic field is `Q(sqrt(Delta_pi))`.
Write `Delta_pi = f_pi^2 D_K`. The actual order has discriminant
`D_E = f_E^2 D_K`, with `f_E | f_pi` and
`Z[pi] <= End(E) <= O_K`. Do not identify the full order solely from a
nonfundamental Frobenius discriminant. Specify the base-field or geometric
endomorphism ring being used; maps must act in the chosen representation.

For an order of discriminant D < 0, use `s = 0` if D = 0 mod 4,
otherwise `s = 1`, and `omega = (s + sqrt(D))/2`.
For `alpha = a + b omega`, derive

```text
T = 2a + sb
d = a^2 + sab + ((s^2-D)/4)b^2
alpha^2 - [T]alpha + [d] = 0
T^2 - 4d = b^2 D
4d = T^2 + |D|b^2
```

For an actual CM endomorphism, norm equals geometric degree. It is not a
field-operation count. The minimum norm of a noninteger element is
`ceil(|D|/4)`: choose |b| = 1 and the smallest trace allowed by parity.

## GLV bridge

If phi preserves a cyclic order-r subgroup generated by P and
`phi(P) = [lambda]P`, its characteristic polynomial implies
`lambda^2 - T lambda + d = 0 mod r`.
Verify the map action; a root is not yet evidence of that action.

The kernel lattice is
`L = {(u,v): u + lambda v = 0 mod r}` with basis
`(r,0),(-lambda,1)` and determinant r. Subtract a nearby lattice vector
from `(k,0)` to obtain `(k1,k2)` and
`[k]P = [k1]P + [k2]phi(P)`.
Two independent short, balanced basis directions support sqrt(r)
coefficient bounds, with constants. Determinant r alone is insufficient.

## Verified educational fixtures

Treat these as explicit synthetic parameter tuples, not standardized-curve
aliases or performance evidence. In repository reports, apply the current
curve registry/identity rules before naming new experimental instances.

```text
Positive fixture:
field p = 43, model y^2 = x^3 + 7, order r = 31
P = (2,12), beta = 6, phi(x,y) = (beta*x,y)
beta^3 = 1 mod 43, beta != 1
phi^2 + phi + 1 = 0, lambda = 5 mod 31
phi(P) = (12,12) = [5]P
k = 14 = -1 + 3*lambda mod 31
lattice basis (-5,1),(1,6), determinant -31
(14,0) - (15,-3) = (-1,3)

Negative fixture:
field p = 167, model y^2 = x^3 + 25x + 36, order = 161
trace t = 7, Delta_pi = -619 (fundamental)
omega = pi - [3], trace 1, norm/degree 155
omega^2 - omega + [155] = 0
On F_167 points: pi(P) = P, so omega(P) = [-2]P.
On the order-23 subgroup: lambda = 21 mod 23.
21^2 - 21 + 155 = 575 = 25*23
lattice basis (2,1),(5,-9), determinant -23
```

In the negative fixture, a constant short relation `(2,1)` forces a second
independent reduced direction to scale with r when lambda remains -2.
Do not transfer this conclusion or this eigenvalue to CryptoPro-B.

## Folding and higher dimensions

An effective automorphism action with mostly size-m orbits reduces roughly
r states to r/m orbits. The birthday heuristic predicts an ideal sqrt(m)
iteration improvement. Price representative selection, cycle handling and
walk quality before asserting wall-time improvement. Check overlapping
actions and field/subgroup applicability before multiplying orbit factors.

Suitable GLV/GLS constructions use four points with eigenvalues
`1, lambda, mu, lambda*mu`. Their kernel lattice has index r.
A proved r^(1/4) bound needs the construction's compatible maps and short
basis theorem. Adding coordinates does not by itself prove that bound.
