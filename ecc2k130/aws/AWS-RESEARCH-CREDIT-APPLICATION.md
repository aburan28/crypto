## 3. Proposal description (paste as one field)

### Problem statement

Post-quantum cryptography is displacing elliptic-curve schemes
because a cryptographically relevant quantum computer breaks ECDLP
in polynomial time. The migration (NIST IR 8547; CNSA 2.0) needs
more than “Shor exists.” It needs to know which *classical algebraic*
methods actually move the bound that a next-generation scheme has
to clear.

Index calculus on elliptic curves — Semaev summation polynomials,
Weil-descent encodings, Gröbner / WDSat solving, factor-base
geometry, residual-walk hybrids — is regularly quoted with an
attractive exponent from one phase (relations, or Gröbner). Those
quotes have been read as statements about the method. On
`E(F_{p^3})` this project has already shown they are not: the
relation phase is genuinely about `n^{1/3}`, the linear algebra
grows closer to `n^{0.68}`, and every built variant costs between
`528×` and `4,000×` Pollard rho at the sizes that fit, with the
asymptotically better large-prime variant crossing rho only past
`2^{230}`. That result is published in this repository
(`research/notes/index-calculus/RESEARCH_RESIDUAL_WALKS.md`, `docs/index-calculus-scoreboard.html`).

The open scientific question is whether any of the *next* algebraic
levers — higher Semaev polynomials, symmetrized decompositions,
quasi-subfield structure, first-fall-degree repairs, new encodings —
moves the **ratio to the floor**, or only the constant. A thread
that cannot state its floor has not started; a thread whose ratio
is flat has not progressed. Answering that, in public, at four
field sizes, is the project.

### Project summary

This is a 90-day, finite measurement campaign on AWS, not an
open-ended walk.

1. Freeze an index-calculus variant (encoding, factor-base size `B`,
   solver, linear algebra) *before* measuring.
2. State the counting floor and the matched Pollard-rho reference
   in one unit, `S = total operations / sqrt(n)`.
3. Run the whole method on the same planted instances. Charge every
   phase. Verify `[k]P = Q` on every completed test. Publish the
   row, including negative results.
4. Classify the change as advance (ratio to the floor fell),
   engineering (`S` fell, ratio flat), relabelling, or accounting.
5. Stop at four sizes or at day 90, whichever comes first. Fit
   exponents only over at least four sizes, and mark extrapolations
   as extrapolations.

Pollard rho is the **reference algorithm**, run on the same group
with the same operation accounting, so a reader can see “is this
better than rho” in one column. Distinguished points and planted
secrets exist so every row can be checked. A run without a verified
answer is discarded. The project will not treat finishing a public
challenge curve as a success criterion.

Prior art already in the open repository includes the residual-walk
negative result above, a frozen ECDLP index-calculus regression
suite, and a public scoreboard that cites frozen experiment files
and never computes a headline from memory. The credit pays to
extend that ledger to the next algebraic variants and to the sizes
that settle an exponent, on GPUs this workstation cannot hold.
