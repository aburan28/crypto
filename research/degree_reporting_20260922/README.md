# Degree diagnostic reporting correction

Classification: **accounting**. This corrects interpretation and presentation;
the generator, matrix construction, elimination, and measured numbers are unchanged.

## What the existing measurements establish

| Legacy name | Actual event | Limit |
|---|---|---|
| `first_fall_degree`, `fall_mean`, formerly `FFD` | First original-generator Macaulay matrix with rank below both row and column counts | Duplicate equations can trigger it; not certified first fall degree |
| `solving_degree` | First bounded matrix that refutes or pins every occurring variable | Not iterative F4/F5, basis completion, or homogeneous regularity |
| `gap`, now `delta_means` | Conditional mean refutation degree minus conditional mean rank-proxy degree | The means can use different subsets; not a paired gap |
| `control_solve_mean` | Pinning degree of shape-matched SAT controls | Every control has the zero root |
| `control_unsat_mean`, formerly `ctrl(unsat)` | Pinning degree of extra-equation SAT controls | The legacy name is incorrect: this generator cannot produce UNSAT |
| `control_expected_solutions` | The retained expression `2^(variables-equations)` | Not this generator's expected solution count; not used to label SAT or UNSAT |
| `unresolved` | Neither refuted nor fully pinned before the degree or matrix limit | Includes multi-solution systems with complete bases; not a degree lower bound |

`random_control_system` samples monomials of degree at least one. Their sums
vanish at zero, for any equation count. Adding four more equations than variables
cannot make this control infeasible. The former `n/a(sat)` decision based on a
density heuristic is removed; unresolved controls are reported as `unres`.
Public Rust names are retained for compatibility; the table and API documentation
state their actual meanings. Consumers parsing the old Markdown headers must
use `D_rank_proxy`, `delta_means`, `D_pin(shape)`, `D_pin(extra)`, and `Dc(extra)`.

Two small algebraic counterexamples explain the limits:

* Duplicating `xy+x` produces two equal rows over columns `xy,x`: rank one,
  two rows, two columns. The rank proxy fires without new information.
* The Boolean ideal generated by `xy` already has a complete basis and three
  solutions. Neither variable is pinned, so the resolution diagnostic remains
  unresolved even when the input describes the complete solution set.

Sweep targets are field abscissas, not independently lifted rational points.
The invariant-subspace ladder changes dimension with extension degree and is
not a fixed-dimension scaling experiment. The mask budget is 64 variables;
these examples provide no measurement at extension degree 131.

## Validation

The focused CI job runs `cargo test --lib degree_reporting_` and
`cargo test --lib control_arms_are_reported_separately`, then checks the example
build. Tests cover both counterexamples and zero-root controls over 96 generated
systems (three variable counts, two equation counts, sixteen seeds).
The source environment used to prepare this correction has no Rust toolchain;
Rust validation is delegated to the recorded CI job, not claimed as a local pass.

There is no performance iteration, full-DLP measurement, or boundary-ratio
improvement in this correction. No new cost is inferred from these diagnostics.
Prior measurements remain historical records, subject to this interpretation.
