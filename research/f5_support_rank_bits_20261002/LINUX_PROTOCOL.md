# Physical Linux complete-call gate for width 6

The corrected width screen and native Apple paired follow-up passed their
predeclared exact-output and counted-work gates. Freeze the next comparison
before running it. The baseline is selective echelon (F5 form 2); the
candidate is the cut-19 exact support certificate with row-basis rank-table
width capped at 6 (F5 form 5). Both arms use one benchmark binary, the same
frozen four seeded systems, direct packed rows, the same builder/unpack flags,
and separate processes. Set the cap explicitly in the candidate process and
record it in each run receipt. Width 8 remains a diagnostic from the prior
paired follow-up; the final 2× ratio uses the direct selective/width-6 pair.

Run on physical Linux x86-64 with AVX2 and BMI2. Rebuild the binary on that
host. Reserve and pin one CPU for the primary gate; run a separate two-thread
control on two reserved CPUs. For each seed and thread count, use one warmup
per arm, five A/A pairs, and five alternating baseline/candidate pairs.
Repeat a contended, failed, or incomplete attempt up to three times, retaining
every receipt. Select the first attempt whose isolation receipt reports no
outside user threads or contended samples and whose 22 calls all complete.

Require matching rank, canonical row space, criterion, rows, columns and
other nontiming invariants. The candidate must return the unchanged original
rows through the cut-19 certificate and keep counted reduction word XORs at
most 35% of selective echelon on each seed. The six smaller cases must match
every nontiming field and not regress beyond that seed's A/A minimum. For
each one-thread n24 degree-4 seed, the paired complete-call median **and**
exact five-pair bootstrap 95% lower bound must exceed 2.00×. The two-thread
control must not fall below its A/A minimum. Report every failed gate and
retain full wall and phase timings, source and binary hashes, host details,
isolation receipts and exact output. This is a solver-stage measurement, not
an IC online or rho comparison.
