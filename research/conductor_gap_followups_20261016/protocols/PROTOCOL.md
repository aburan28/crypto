# Conductor-gap follow-ups, preregistration v1 — 16 October 2026

Authorization: the user requested all five proposed experiments, a PR and tracking. This protocol preserves their workloads. Arithmetic-only checks and controls do not count as ECDLP solves. The prior 765 attempts remain a separate frozen campaign.

## Workloads and order

One CPU-pinned measured process at a time, in this order. Twenty of the existing 100 certified D=-19 pairs are sampled without replacement by native StdRng seed 2026101601; exact indices and the complete ordered job lists are committed before the campaign. No fixed physical-host/frequency isolation is available: this is L0 local isolation. No local compiler or other solver may overlap the crossover. Retain process, resource, exit-status and verification receipts for every attempt.

1. **Crossover: 240 attempts.** Twenty gaps, four fresh public targets per endpoint, three arms per gap/target block: crater CM, the same crater recurrence, floor recurrence. The two crater arms share their complete point/query inputs. Across 80 blocks the six arm permutations occur 13 or 14 times; block order is randomized. Each arm uses four seed columns, 2048 orbit levels (8192 points), a one-billion-query cap and a 240-second native wall safety cap. A separate 900-second process watchdog also covers independent replay.
2. **Yield: 400 attempts.** Twenty gaps, ten fresh public targets/query seeds per endpoint, recurrence on both endpoints; 8192 points, a common 300-million-query cap and a 180-second native safety cap. Preserve every hit, proportional-column rejection and rank increment with its zero-based query position. A successful recovery may stop early. Failures/censors remain in the denominator. Report hit counts, queries exposed, independent-row yield, rank-time events and query-capped success probabilities. Compute restricted mean queries through the common cap only when all non-success observations actually reach that cap; otherwise report lower/upper bounds for prematurely censored observations rather than assuming they exhausted it.
3. **Rho: 400 attempts.** Twenty gaps, five public targets per endpoint, two independently domain-separated partition salts. Jump-table/start seed is held fixed for the two salts on a given target; salt is a bijective word permutation of the native point key before the existing walk hashes. Negation canonicalization uses the original unsalted curve key and is identical across salts. The salt changes both jump partitioning and distinguished-point selection; it does not isolate these two walk-design choices from each other. Use one frozen tuned negation walk, with one billion charged walk operations and a 900-second process watchdog. Record group and field operations, canonicalization counters, key calls, collisions/restarts, complete process CPU, and verified recovery. Compute operations/sqrt(r) separately from CPU/operation. A second walk implementation is a separately priced future replication, not part of the primary denominator. Isomorphic-coordinate calibration is specified below.
4. **Orbit audit: 800 arithmetic-only jobs.** All 100 existing gaps, both endpoints, lengths 256/512/1024/2048 per seed (4L points). Query budget zero. Construct each pair table and record distinct pair-sum abscissae; replay every orbit by direct scalar multiplication. On craters independently apply the degree-5 map along every adjacent orbit pair. Certify multiplicative and signed scalar periods independently in PARI. Preserve any point/seed-orbit collision as a failure, rather than dropping the gap. Known-generator Q is used only in this zero-query arithmetic audit.
5. **Dose response: 320 attempts.** First four classes with D=-19, then an additional four with D=-43, each with Frobenius conductor 35,55,65 or77. Each class has explicit strata 1,ell1,ell2,ell1*ell2, five fresh targets per stratum, recurrence IC and matched-target rho: 160 IC plus 160 rho attempts. The field, trace, group order and cofactor are exactly equal within each class; the certified group is prime order with cofactor one. The IC caps are one billion queries and 240 native wall seconds; rho caps match the rho arm above. These are small multi-prime conductor controls, not large-prime or 96-bit barriers. Do not extrapolate a trend to large prime gaps.
6. **Orbit follow-up: 40 additional IC attempts.** After the arithmetic audit, select ten gaps with the largest summed crater/floor pair-table abscissa collision counts at L=2048 (8192² minus distinct keys per endpoint). Break ties by the frozen hash label `overlap-tie/<gap>`. Sample ten other gaps uniformly with StdRng seed 2026101603. One fresh target on each endpoint gives 20 selected plus 20 held-out attempts; shuffle with seed 2026101604, 300-million-query/180-second caps. Report this selection as exploratory. The random remaining-gap sample is a held-out comparison, not independent population confirmation.

Public targets are obtained by domain-separated SHA-256-to-abscissa rejection sampling, choosing the smaller nonzero ordinate and checking subgroup membership. Preparation never computes their logarithms. Matched seed labels on different curves do not imply equal hidden logarithms or identical group points. IC seeds are four public prefix points, exactly as in the original solver. The linear system has four seed logs and one target log; it does not have 8192 independent columns.

## Verification and accounting

Inputs, scalar parameters, native/Rust source, prepared lists and executable digests are frozen before launch. Each attempt has an immutable input, stdout/stderr, native point/row/event files where applicable, process timing/peak RSS/exit code and a result seal. The independent Rust verifier reconstructs each base by scalar arithmetic and checks every hit, duplicate decision, rank, relation equation, query position and recovery [d]G=Q. Rho recoveries also reject [d+1]G=Q. PARI independently certifies all new strata using prime proofs, a Hasse-unique point-order witness, the Frobenius discriminant, and the class polynomials of every conductor dividing fpi.

Complete process CPU includes input reading, native launch, orbit/table/collection/recovery and Rust replay. Public-target, curve and CM-parameter preparation, build, persistent scheduler, receipt sealing and later duplicate audit are outside this interval and are reported separately. Native setup/orbit/collection clocks remain supplementary measurements. Do not call this fully priced algebraic IC or a complete IC/rho speedup.

Freeze query and operation counts before statistical analysis. For fully recovered panels compare paired query counts and complete process CPU, with 10000 whole-gap bootstrap draws, seed 2026101602. Keep fresh seeds nested within each gap. For capped panels report budget-specific outcomes, all observed work and censoring bounds; do not compute successful-only solve-time ratios. Treat the eight dose classes as clusters; keep CM-family summaries separate. No equivalence or general hardness claim follows from an interval containing one. The scalar recurrence is generic arithmetic available on either endpoint.
