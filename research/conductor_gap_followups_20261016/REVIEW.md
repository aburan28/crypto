# Review the follow-up experiments

Start with the [status ledger](README.md) and [frozen protocol](protocols/PROTOCOL.md). All five requested experiments retain their full specified scope. Completed construction/certification, ongoing timing and queued work are separate rows.

1. `native/followups.rs` prepares unknown-log public points, fixed samples and balanced crossover blocks; runs native children; and independently checks complete base vectors, every relation hit/rejection, query positions, rank progression and recovery. Identical bases are retained losslessly by SHA-256 as compressed content-addressed artifacts.
2. `native/folded_events.cpp` adds hit/rank event logging to the unchanged native collector. `CM_Q` generalizes the same recurrence to q=11 for D=-43. The D=-43 floor uses generic scalar arithmetic, not a claimed small-degree endomorphism. `folded_noevents.cpp` is the instrumentation control. Exact small comparisons and one large comparison are retained in `calibration/` and `results/instrumentation-controls.json`.
3. `native/tracking.rs` checkpoints each process, freezes sources/inputs/executables, guards CPU-0 serial launch against local compilers/solvers, and records failures. The local guard does not attest physical-host isolation. A scheduler-only diagnostic pause did not stop measured children or drop attempts.
4. `native/analysis.rs` verifies sealed records before aggregation, uses whole-gap bootstrap samples, suppresses contrasts after execution failures, and refuses final analysis until all 2,216 execution receipts exist. Query-censor bounds, observed attempt costs and verified solve costs must remain distinct. The small dose-response panel has only four classes per CM family.
5. `native/certify_dose.gp` independently verifies all 32 explicit models, rigorous p/N primality, Hasse-unique group-order witnesses and all divisor-order class polynomials. `native/certify_orbit_orders.gp` checks 100 multiplicative/signed periods with prime-factor minimality witnesses. These are arithmetic certificates, not a new full Lean formalization.

`prepared/source-commit.txt` identifies the source revision; `prepared/freeze.json` pins exact pre-run bytes. Live execution state and the current incomplete attempt are deliberately ignored by Git. Immutable completed attempts are checkpointed explicitly, then all final evidence will be published after completion. The original study's manifest is preserved under `inputs/`; it describes its historical checkpoint. The maintained manifest is refreshed when shared sources change.

Validation is documented in the ledger. Do not read a pending CI check, a capped attempt, a source-reported historical ratio, or a queued panel as a completed solve. The cheap crater map remains a concrete arithmetic distinction; generic recurrence and MITM controls remain available on the floor. No intrinsic ECDLP hardness gap is established by preparation or by the first few targets.
