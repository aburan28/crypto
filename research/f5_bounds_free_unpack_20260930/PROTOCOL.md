# Matrix-F5 bounds-free direct unpack: frozen local screen

## Hypothesis and reference

The direct output loop materializes about 13.7 million `F2BoolMono` values on the frozen n24 degree-4 call. It indexes the sorted `cols` array once per emitted term. This experiment tests whether checking each packed row's valid column span once and removing each per-term bounds check improves the complete call. The candidate uses the existing exact-size preallocation, bit order, `u64` column values, direct writes, and return type. `KIC_F5_UNPACK_UNCHECKED=0` is the current reference; `=1` selects the candidate only for the n24 degree-4 call with direct unpack and at least 4,096 columns. A row with too many words or set padding bits falls back to the existing checked decoder. The check must make every unchecked column load provably in range. The candidate must preserve raw and canonical fingerprints, rank, terms and all counted operations.

The immutable reference is main commit `c93c3b1b8723c37611f49ab2228d49a73b421829`. Source SHA-256: `matrix_f5_f2.rs` `bf35680f431ab7ac13a7615d334ec9b060217b84bdde36f03ce00319491d42da`; `gf2_elim.rs` `6fd3f10ef8e681490784c624e703eeb8fa887c5817ec9bdf34844e3f943c7f5c`; benchmark `f4_f2_bench.rs` `d40f9f0c76e5c56c9f4a52596b9edef41f321aa3d70cfb023c4ba21fdde70336`; isolation wrapper `ff59e53fd5566078ad493c8be0d06168699c4fd194bc881d99df19fa20e007ef`. The pending POPCNT candidate in PR #1033 is separate and not in either arm.

## Workload, preservation, and decision

Run one release binary under `tools/isolated_bench.py busy` on the local Apple ARM64 host. Fix one Rayon thread, selective echelon, fused row build, direct packed rows, direct scalar unpack, branchless strip, Gray-code table reuse, four tables, and disable deferred-above, word batching and AVX-512 unpack. Run all seven F5 benchmark cases for seeds `0` and `badc0de1`. Per seed, run one warmup per arm, five reference/reference A/A pairs and five alternating reference/candidate A/B pairs. Preserve every process, failure, timeout or OOM, source/binary hash, host and load, selected route, raw/canonical output fingerprints, rank, rows, columns, terms, criterion and reduction operations, and phase and complete-call times. Release tests must compare the candidate to checked direct unpack on sparse, dense and partial-word rows and verify the malformed-row fallback. Measure the full F5 call; unpack phase is a diagnostic.

This local screen is exploratory. Advance to a separately frozen isolated x86-64 replay only if every process and case is exact; both seeds' primary `f5_n24_m24_d4` paired full-call medians are at least 1.04 with exact 3,125-resample bootstrap 95% lower bounds above 1.02; and no smaller-case paired median falls below its own A/A minimum. Any missing or failed call prevents promotion. If the local gate fails, archive the tested patch and all raw receipts, remove the runtime option, and keep only research evidence. The user's further 2× target still requires a qualified one-thread full-call median and lower confidence bound above 2.0. These are F5 solver-stage measurements, not IC one-target DLP or rho speedups.
