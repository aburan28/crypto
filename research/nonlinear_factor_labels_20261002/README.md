# Nonlinear factor-base label search

This experiment is preregistered in [PROTOCOL.md](PROTOCOL.md).  It searches
the 30 affine-equivalence classes of all 40,320 bijections of an eight-element
factor-base label cube.  It uses only native Rust.

Implementation, discovery results, the frozen winner and untouched holdout
evaluation are pending.  No ECC2K-130, end-to-end index-calculus or speedup
claim is made by this preregistration.
