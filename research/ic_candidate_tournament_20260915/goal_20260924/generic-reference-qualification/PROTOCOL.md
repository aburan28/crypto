Use the same controlled generic executable, same one-point jobs and fifteen
development fixtures. Include both generic IC configurations and all six generic

(720 native children), within a 400-pair cap. Fix scheduling seed 2026092664 before
execution. Randomize case/arm order and alternate the two modes' order within
adjacent pairs. Keep the same CPU, environment, memory and process limits.

outputs must survive independent transport replay.

Enabled mode receives full existing scientific admission. Legacy mode lacks
embedded build/runtime metadata, stored matrix snapshots and observed dispatch;
bind its executable externally and independently verify its group certificate,
query law and base. Compare checked query/counter histories, base and recovered
logs with enabled mode. Do not fabricate missing legacy fields or present it as
a fully admitted candidate. Legacy scientific phase costs and qualified IC

lower half. Separate modes receive distinct execution numbers on the same

directories. Legacy `OBS1` identifiers never become `IC1` candidate results.

This measures **whole-mode effects**, including serial versus single-thread
Rayon collection, matrix/batch reporting and tracing. It does not isolate timer
overhead or all certificate-generation overhead. Both modes retain witness
reporting. Report each mode's supplied-point outer interval and process wall time,

use of that source; passing supports only the explicitly fully charged,
