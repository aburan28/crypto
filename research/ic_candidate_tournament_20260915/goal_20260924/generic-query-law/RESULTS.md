# Generic query-law controls

Classification: **accounting and correctness admission**. No solver algorithm
changed and no candidate was promoted. One improvement round is complete, its
incumbent remains selected, and two rounds remain.

The independent Python adapter agrees with 7,436 values generated by the real
pinned Rust crates: 28 streams of 257 integers plus 24 panels of 10 trial-keyed
probe values. This exercises ChaCha block boundaries, rand's rejection sampling,
PCG seed expansion and wrapping-u64 trial keys. The upstream StdRng construction
vector passes separately. `StdRng` is not assumed stable across crate upgrades:
this adapter names rand 0.8.8 / rand_core 0.6.4 / rand_chacha 0.3.1 explicitly.

All 35 IC reports retained by PR 803 replay under their original jobs. All 47
fresh controls also pass: 40 complete verified IC solves and seven deliberate
preparation failures. The fresh panel covers seven PDP backends, dense/sparse
final LA, n9 curves with both coefficients, and n9/n13 subgroup-orbit bases with
active and inactive collection windows. Twelve controls retain 128-query batches,
crossing the 64-query collection-run boundary. Their aggregate ordinary-query
ledger has 1,797 witnesses and two identity queries; the seven preparation
failures are insufficient-data outcomes, not negative PDP claims. These fixed
correctness fixtures are not estimates of natural relation yield.

Ten new tests include two deliberately substituted **true group equations**:
one changes a collection query, the other changes descent coefficients while
preserving the query point and recovered scalar. Ordinary group replay accepts
both; the new sampler check rejects them. Wrong seeds, batch partitions, bounds,
method/target declarations, early preparation failure and changed window dispatch
are rejected as well. A bit flip in a Rust vector is detected. The final local
harness run has 136 passing tests and two platform skips (138 total).

The checker derives the sampling path from the externally frozen job and actual
geometric base length, checks every attempted coefficient, and binds its receipt
to the canonical job, ledger and checker dependency hashes. The Linux integration
panel adds three window controls (44 cases total); its profiled active-window
case must agree exactly with native query-law replay. Its real-Rust vector check
also runs on every applicable CI execution. CI results belong to the PR checks.

This is still not full scientific admission. A query-law receipt cannot prove
the executed source/ISA, exact base construction, relation-matrix construction,
rank-based stopping criterion, exclusive timing, or implementation quality.
Comparative online time, cold cost, instruction cost, S and speedup remain null.
The archived optimized producers and the sealed round-one evaluator are unchanged.

## Evidence and replay

`PROTOCOL.md` freezes the controls. `rust-vectors.json`, `worker-raw.jsonl`,
`inputs.json`, fixture files and `environment.json` retain source/input/binary
identities and raw output. `summary.json` and `historical-replay.json` preserve
the first checker pass. `final-replay.json` rechecks those same 47 fresh reports
after adding the early-preparation-stop guard; it does not rerun or replace the
measurements. Initial and final test logs remain separate. `controls.json` hashes
the final code and retained evidence.

From the repository root, using the pinned lockfile:

```sh
cp research/ic_candidate_tournament_20260915/ci/Cargo.lock Cargo.lock
cargo build --locked --release --example ic_tournament_worker
cargo run --locked --release --example ic_query_law_vectors > /tmp/ic-query-law-vectors.json
python3.12 research/ic_candidate_tournament_20260915/generic_query_law.py \
  --rust-vectors /tmp/ic-query-law-vectors.json
python3.12 -m unittest discover -s research/ic_candidate_tournament_20260915 -p 'test_*.py' -v
python3.12 research/ic_candidate_tournament_20260915/goal_20260924/generic-query-law/run_controls.py \
  --worker target/release/examples/ic_tournament_worker \
  --vectors /tmp/ic-query-law-vectors.json --out /tmp/ic-query-law-fresh
```

Choose a new output directory on each execution. The runner preserves stdout,
stderr, timeouts and unsuccessful controls before reporting failure. The current
local evidence is macOS arm64/Python 3.12.13/Rust 1.93.1; Linux CI pins Rust 1.94.1
and Valgrind 3.22. No timing comparison is inferred across these environments.
