# Fresh native ordinary-query registration for the n17 F5/SAT study

This protocol extends the target-free worker and original-source controller
without reopening the consumed SAT/F5 controls or the three closed tournament
confirmation sets. The first registered arm is the actual bounded MatrixF5
preparer. External CryptoMiniSat is a separate arm with its own native assets,
registration, publication and one-use execution. Neither arm is the worker's
built-in Rust CDCL solver. These are preparation stages of complete IC
pipelines, not complete target-DLP results.

The exact frozen seals and full data-only archives are in the
[registration result](REGISTRATION_RESULT.md).

## Frozen question and input

The proposed common natural panel has 512 target-free ordinary queries from
`probe_scalar(2026100311, trial, 65587)`, trials 0 through 511. The two arms
receive the same ordered public points and retain every start/completion,
including budget exhaustion, timeout, exact geometric negative and verified
witness. The producer must finish the fixed count even if relation rank reaches
29 early. A partial panel remains a retained partial result; never refill or
resume its consumed registration. The n17 curve, generator, three-summand
decomposition, standard six-dimensional subspace, 63 geometric points, 62
subgroup-usable points and 29 folded columns are reconstructed independently.
Planted controls and the old 216-query certificate are never yield estimates.

The first F5 config is [f5-512-config.json](f5-512-config.json). Its collector
uses one reusable MatrixF5 engine with degree 3 and node budget 8192, not a
claim of a complete incremental F5 algorithm. The CMS arm will use its own
versioned [CMS config](cms-512-config.json) with the same 512 scalars and the accepted external
exporter/CryptoMiniSat archive. Both record explicit per-query and outer
deadlines; a timeout is an outcome, not a negative mathematical proof.

The host is a physical macOS ARM64 M4 Pro in an uncalibrated environment.
The busy lock serializes local jobs but supplies no physical CPU isolation.
Preparation phase times are exploratory diagnostics. No CPU speedup may be
promoted without the user-required isolated-host/noise receipt.

## Hypothesis, reference and stop rule

The falsifiable stage hypothesis is that each real solver family can turn this
fixed natural panel into 29 independent verified projected rows and recover
all 29 column logs. The independent finite-group pair-complement oracle is the
reference for whether each query has a geometric decomposition. It certifies
negative answers and identifies feasible queries that a bounded solver missed;
it does not replace solver execution or supply a timing baseline. The two arms
are paired by trial/point, but neither is treated as an incumbent complete IC
solver. That comparison and same-point rho belong to the later one-target
protocol.

Each arm qualifies for a later complete-solve experiment only if its original
frozen audit passes, all 512 starts and completions are retained, every witness
readds to its query, every claimed negative is geometrically impossible, rank
is 29/29, and all column logs pass independent scalar replay. A complete panel
with rank below 29, a zero-yield arm, or an arm with feasible inconclusive
queries remains a measured outcome; it is not repaired by filling in oracle
relations. An interrupted panel remains censored. The one-use run stops after
512 queries or its 12-hour outer deadline; a consumed registration is never
retried. A revised budget or solver needs a new preregistration and source
freeze.

Report all 512 outcomes, including timed-out and budget-exhausted attempts;
verified-witness rate, accepted-row rate and novel rank per query; uncertainty
for the rates; and exploratory paired cost differences with uncertainty. The
charged preparation interval includes initialization, all query generation,
encoding/solver and relation checks for successful and failed queries, matrix
building, final relation LA and group replay, plus measured controller setup.
Its exclusive phases must sum to the observed preparation wall time. Report
cost per useful row only with its zero-denominator case explicit. No stage
rate or cost is a one-target IC speedup.

## Publication before the sole dispatch

Freeze only a clean committed source tree and the ignored but hash-retained
Cargo.lock using the accepted Homebrew toolchain. Each arm receives a new
`ordinary-control-freeze` capsule with `validation_only=false`, its own
immutable source/vendor/dependencies, release worker and checker, build
receipts, config/host bytes and external registration seal. Freeze calls only
`build-identity`; no query or solver runs. No old capsule or archive restoration
may be executed.

`ordinary-control-publish-registration` requires the exact external seal,
the full unconsumed original capsule and original build receipts. It archives
every sealed regular file, copies the small sidecars, then immediately checks
the complete USTAR inventory as data. Its separate
`ordinary-control-replay-registration` command verifies that same published
registration on another host without extracting or launching a binary. The
question and stage are distinct from validation-only build custody. Both
outputs assert zero scientific worker calls, no admitted execution and null
online time/speedup. Publication, external seal, config and source commit must
be committed and pushed before `ordinary-control-execute` is called once
from the original frozen checker. Replaying a publication never authorizes
running its archived binaries.

The execute command requires `--publication`; it fully replays that
scientific registration as data before creating the execution and claim. It
retains a preflight receipt in the execution directory. The frozen audit
replays the same publication again and requires the retained receipt and
terminal digest to match. A missing, validation-only, modified or differently
rooted publication therefore cannot yield a source-admitted panel.

The original execution consumes a create-only claim before the sole worker
launch. The independent frozen audit must bind source/build/assets, exact
worker and role invocations, output/model files, PID ledgers and drains, all
512 query starts/completions, geometry, verified rows, rank/log replay and
exclusive phase clocks. Preserve terminal failures, interrupted prefixes and
failed attempts. Only a passing original audit can admit natural yield for
the exact pipeline. Report verified yield and novel-rank rates with
uncertainty, including zero-yield cells and cost per useful row.

This registration does not assign an IC1 candidate ID by itself: the complete
factor-base, target-PDP, relation, final-LA, descent and implementation manifest
must be fixed before comparing complete solvers. Later fresh public points
require an exposure census, canonical EC1/IC1/workload/run identities, and
independent one-target scalar replay for F5, external SAT, the incumbent and
strong same-point rho under one frozen envelope. No stage winner substitutes
for the complete solver or guarantees a global tournament winner.
