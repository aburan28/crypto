# External SAT public-point source boundary, version 1

This extends the prepared n17 source interface in PR #1354. Its sole supported
instance remains the disclosed educational field/curve/subgroup. It does not
select or launch a native solver, grant execution admission, or reopen a closed
control. The new backend contract requires durable start and completion records,
original source/model retention, and native role drain. Those obligations must
be implemented and independently audited by a new frozen one-use executor.

## Source controls before scientific execution

Hypothesis: a target-free checked log table can support external SAT public-point
recovery with failed attempts retained, independent scalar verification inside
the online interval, and explicit rejection of corrupt source/model or durable
record failures. Valid source models without a full-point lift remain separate
unresolved attempts; they are not invalid assignments or proofs of no relation.
Native UNSAT is a source claim pending independent geometric negative proof.

The not-yet-executed ordinary native preparation path now retains this same
distinction as `nonlifting_model` and continues the fixed panel. Its independent
source gate requires a valid ANF/CNF assignment with no full-point lift for that
assignment; an invalid assignment cannot take that label. The mathematical gate
treats it as inconclusive with no row, and can separately find the query feasible
through another decomposition. It does not assert global geometric UNSAT or new
natural nonlifting frequency. Original archived source snapshots remain unchanged.

Controls use only the retained disclosed n17 mathematical preparation and ANF,
CNF and assignments in `prepared-report-contract-v1/sat-source-check`. They run
no exporter, SAT solver, new target search or old controller. A scripted
inconclusive first response is a transport/accounting control, not measured
natural failure yield. A valid assignment tested against a different point
checks the lift helper's rejection, not validity of that assignment for the
different source instance. Original fixtures and registrations remain unchanged.

Both target and ordinary paths use `nonlifting_model` for a verified assignment
with no full-point lift, retain the attempt cost, contribute no relation, and
continue within the frozen query cap. Source corruption and durability failures
remain fatal. The prepared-state census explicitly verifies 63 distinct
geometric points and 62 distinct nonidentity cofactor images before quotienting.

Success requires independent cofactor-image log derivation, positive retained
model/scalar replay, all failed attempts and durable boundaries preserved,
model/manifest corruption rejected, failed completion excluded from success,
and closure of five exclusive online phases. Preserve each failed local test
output, stop on assertions/compilation failures and rerun only source controls
after fixing code. Run all native tests through the shared busy wrapper.
