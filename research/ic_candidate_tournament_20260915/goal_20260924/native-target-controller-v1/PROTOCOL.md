# Native target controller and original runtime audit, version 1

This extends PR #1369 on the disclosed educational n17 F5 fixture. The full
goal remains complete source-bound F5 and external SAT admission, natural yield
and failed-attempt accounting, and a fresh paired incumbent/rho comparison. The
three confirmation sets and all consumed control registrations stay closed.

Hypothesis: a separately frozen target controller can consume its own claim
before the sole worker launch, retain exposure/invocation/exit/watchdog/drain
and original byte custody, and independently bind the resulting transcript to
the original source/build and native preparation. The controller must run from
its original frozen path with matching compiled source/build identity. Never
execute an archived restoration or a development/validation-only worker.

Freeze copies a complete coherent committed source and embedded data tree,
vendors dependencies offline, records tool/build/environment receipts, builds
the worker and checker with separate target identity variables, and invokes
only worker identity reporting. Validation-only builds may use an explicit
non-executable preparation-binding stub for build controls, but cannot dispatch.
A scientific target freeze requires the original completed native preparation
and its exact external seal. Publish the target registration before its sole
scientific execute call. Input loading, build and preparation audit are outside
the one-target online interval; actual target-dependent work and record writes
remain charged inside the worker's five phases.

For a validation-only build, `target-control-publish-build` creates a bounded
USTAR/Gzip copy of every sealed regular file plus the original small sidecars
and build receipts. It requires the external registration seal, rechecks the
original source/build and unconsumed state, and immediately runs
`target-control-replay-build`. Replay treats the archive solely as data: it
checks its complete member inventory, hashes, original invocation paths and
environment, source manifest, binaries and receipts without extraction or
execution. Archive or receipt mutations must fail. A passing replay says only
that the validation build has portable byte custody; it cannot admit a solver,
fresh target, relation-yield estimate or speedup.

Execute must retain a durable consumed claim and target-exposure record before
launch and never resume. Terminal receipts must survive success, failure and
timeout and bind immutable source, worker/controller bytes, exact invocation,
single-thread environment, original output, PID ledgers and all child drains.
Failed/timeout runs remain evidence and cannot count as wins.

Independent audit launches no worker or solver. Require original target capsule,
compiled checker identity, full offline build receipts, original consumed claim,
worker start/terminal identities, exact stdout/stderr/invocation/drain receipts,
and the original preparation auditor's invocation and result. Reconstruct target
mathematics and all complete query files using PR #1369's independent arithmetic.
Check clock closure and fit measured online/setup/audit intervals within the
original outer worker interval. Missing phase costs remain unknown. An admitted
failed budget-exhausted execution is a failed target, never verified recovery.
Inspection may retain an interrupted prefix without runtime admission.

Controls use synthetic receipts and file-only children, historical mathematics
as data, and development/validation rejection. No F5/SAT search or preparation
panel is authorized by these controls. If an offline build is exercised, retain
its full source/bin byte custody and explicit validation-only/no-dispatch labels.
Preserve original compile/test/build failures. All builds/tests/archives/parses
and data replay use the shared busy wrapper.

Actual new ordinary F5/CMS source admission and one-use panels, accepted
preinitialized SAT transport, canonical identities, fresh paired targets/strong
same-point rho, operations/memory and physical host isolation/noise remain required.
Source controls and build custody cannot establish new yield or speedup. The full
goal remains incomplete until those scientific gates are met.
