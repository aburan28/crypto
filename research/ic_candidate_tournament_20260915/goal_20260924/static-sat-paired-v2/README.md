# Corrected SAT IC one-target registration

This directory freezes the static-SAT arm for the next fresh paired target.
The [protocol](PROTOCOL.md) and [panel](panel.json) specify source receipts,
ordinary query and target seeds, attempt limits, conflict censoring, exact
online clock endpoint and full-rank/scalar-replay gates. Candidate and
workload manifests are generated and sealed before the first job. No result
or speedup is claimed by the registration alone.
