# F5 per-attempt evidence contract, version 1

This source change extends PR #1359 on the exact disclosed educational n17
fixture. It launches no new scientific solver, exporter, preparation panel or
comparison and never reopens the three closed confirmation registrations.

Hypothesis: the existing seeded F5 target loop can publish each query start
before decomposition and each completed verdict before proceeding, retaining
all failed attempts and stopping on a failed evidence write without changing
the query law, F5 engine or algebraic recovery. A newly frozen worker must
implement those callbacks as exclusive durable files. In-memory controls do
not establish file custody, native execution or interruption survival.

Success for this source stage requires retained-data controls proving event
order, unchanged seeded coefficients/verdicts, no decomposition after a failed
start, no next query or admitted answer after failed completion, preserved
partial reports, invalid public-point rejection before callbacks, independent
relation/scalar checks inside the online interval and five-phase closure.
Stop on a source assertion or compilation failure; retain its original output
and rerun only after a source fix. Use the shared busy wrapper for native builds,
tests and parsing. Historical transcript data remain disclosed controls, not
fresh targets, natural yield, new solver measurements or a matched reference.

Keep the ordinary diagnostic API available. The new recording entry is bounded
to n17, three summands, MatrixF5 degree 3, node budget 8192, at most eight seeded
queries and no direct-relation fallback. Start records identify trial and a/b;
the enclosing target record supplies Q, so the independent auditor reconstructs
the public probe. Completion records include the complete PDP verdict, indices
and solver counters. Record callbacks are target-dependent and charged inside
the online interval. Target-independent prepared solver construction stays
outside it. The worker/controller's own launch and loading must also stay
outside the headline interval in the future native executor.

A failed start leaves an unfinished trial with no decomposition result. A
failed completion retains the computed attempt in memory for postmortem but
cannot assert its durable publication. Neither failure qualifies a successful
solve. An interrupted prefix is useful evidence, not a completed run or global
negative proof. Source callback responses cannot set admission flags. Native
preparation source/yield audit, the new one-use executor, actual durable file
writer, watchdog/drain, canonical identities, fresh paired incumbent/rho and
host isolation/noise receipts remain required. All admission/promotion flags
remain false and speedup stays null; there is no measured boundary ratio here.
