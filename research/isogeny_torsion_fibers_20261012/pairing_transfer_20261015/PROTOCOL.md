## Hypothesis, boundary, and attribution

The question is whether an executable nondegenerate pairing transfers the *same* unknown scalar from `E(F_(p²))[r]`, `E:y²=x³+1`, to a cheaper multiplicative DLP after every construction and transfer cost is charged. The null is a failed pairing construction or a cold cost at least the same-target matched negation rho. The fixed generic two-class counted-operation floor is `S_floor = sqrt(pi/4) = 0.886226925` operations per `sqrt(r)`; the measured reference is rho on the same `G,Q,r`. A second charged six-class rho reference is desirable because the source has extra automorphisms. A pairing result is generic to the chosen subgroup; it is not evidence that the torsion-coordinate `χ` oracle improves decomposition.

The first cell uses `(p,ν,r)=(61,2,19)`, `G=((25,0),(0,35))`, `Q=((20,0),(0,26))`; the second uses `(271,3,61)`, `G=((95,0),(0,126))`, `Q=((131,0),(0,264))`. The solver reads a stripped input record containing only these public fields and no `answer_scalar`. The original fixture answer remains confined to a separate post-solve checker. The source ICV1/EC1 records stay those in the fixture. No new target or selected subgroup may replace a failed cell.

## Construction, exact checks, and frozen run choices

Present the pairing evaluation field as `K = F_(p²)[z]/(z^m-a)`, with `m=9` at `p=61` and `m=5` at `p=271`. In `F_(p²)=F_p[s]/(s²-ν)`, select `a` by ascending packed-coordinate order among nonzero elements that pass the necessary non-power test; independently certify irreducibility of `z^m-a` by the monic-polynomial Frobenius/gcd criterion before treating the quotient as a field. Record the exact modulus and certificate. The output root-of-unity fields have minimal degrees 9 and 10 over `F_p`; the evaluation fields have degrees 18 and 10. At `p=61`, solving the output DLP in the full evaluation field is an explicitly priced implementation choice, not a claim about an optimized minimal-field representation.

Compute `#E(K)` from the frozen `F_p` trace by the integer Frobenius recurrence and verify the relevant `r`-adic valuation. Generate candidate `x` coordinates deterministically from the per-cell seed `0x504149520000003d` or `0x504149520000010f` using `StdRng`; lift by an exact finite-field square root, project with the computed cofactor, and keep the first point `H` with `[r]H=O`, `H≠O`, `H∉⟨G⟩` and no Miller pole. Charge *every* rejected x, lift, projection, independence check and pairing attempt. Freeze the selected `H`, modulus, and selection receipt before the paired timed solve; the timed cold arm must redo the same selection and charge it once.

Compute the reduced Tate values `α=t_r(G,H)` and `β=t_r(Q,H)` using a native Miller loop and final exponent `( |K|-1 )/r`. Require `α^r=1`, `α≠1`, and `β^r=1`. Solve `β=α^k` with a native baby-step/giant-step solver given only `α,β,r`; it must return `k mod r`, not inspect the fixture's answer. A separate native process independently checks `[k]G=Q` using independently implemented `F_(p²)` and curve arithmetic. Check bilinearity on additional public multiples *after* the primary solve and retain any exception or failed attempt.

Three deterministic rounds per cell use seeds `0x5041495200001000 + 256·cell + round` for the rho walk, with `cell=0,1` and `round=0,1,2`. Interleave pairing, negation rho and rho A/A in each round. Keep the source target and rho algorithm/cap identical to the preceding eight-arm study. A row stops at a verified answer, 4,096 candidate x coordinates, 512 acceptable-order pairing inputs, `10^7` extension-field multiplications, 512 MiB peak RSS, or 15 minutes of current-thread CPU, whichever comes first. A stopped or failed row stays in the records and has no speed ratio. If the first cell fails exact pairing checks, do not run the second cell as though the transfer were validated.
