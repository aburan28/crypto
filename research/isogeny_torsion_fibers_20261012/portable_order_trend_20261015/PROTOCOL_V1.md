# Portable cost and larger-order different-j screen, V1

Status: frozen before the new screen or analysis runs. This study extends the
checked order-229 seven-arm comparison. The public curve family is
`E/F_p: y²=x³−21x+37`, with rational 3-torsion point `T=(3,1)` and the
explicit Vélu destination used in the prior audit. Only public synthetic
curves and subgroup targets are eligible.

## Questions, boundary, and controls

1. Price the existing order-229 run in the repository's portable counted unit,
   `S_group = (adds + doubles)/(N sqrt(r))`, for every cold target prefix.
   Count common setup, relation setup, every target's query or rho work, and
   final scalar verification. Carry the **separate** base-field multiplication
   and inversion axes as `M/(N sqrt(r))` and `I/(N sqrt(r))`. These axes overlap
   group work and must never be summed with `S_group`. Report all unpriced
   hash, map, table, row, allocation, startup and I/O work explicitly. The
   complete portable `S` remains bounded until those terms have a measured,
   pinned conversion. Use complete direct source BSGS and negation rho on the
   exact same target prefix as references; retain rho A/A. The generic
   two-class collision floor is `sqrt(pi/4) = 0.886226925` per target.
2. Screen ascending primes `223 <= p <= 607`, `p = 1 mod 3`, in the exact
   family above. Require nonsingular source/destination, kernel order three,
   distinct `j`, equal independently counted base-field orders, and a prime
   factor `r >= 257`, `r != 3`, of multiplicity one in
   `#E(F_(p²)) = (p+1)²−t²`. Take the largest eligible factor of each row.
   Select the first three **distinct** eligible subgroup orders greater than
   229; continue to the upper bound and retain every rejection. Existing
   order 229 is the fourth, smallest panel cell. If fewer than three new
   orders appear, report the exact bounded census and freeze a new screen
   range before extending it.

The larger-order hypothesis is that full rational-image relation support and
its cold cost change with `r`. A support increase or one locally faster phase
is not a full-method crossover. The stop condition is the complete ascending
prime range, a 180-second whole-screen wall ceiling and 512 MiB RSS ceiling.
Any cap exit is censored. The screen checks 64 seeded homomorphism pairs for
each accepted row; independent arithmetic replay is required before a pair
can enter a solve panel. A subsequent complete panel must keep source,
isogeny-image, destination-direct, full-image, source BSGS, negation rho and
rho A/A; 64 distinct public targets; prefixes 1, 4, 16, 64; three rotated
rounds; exact relation recovery and separate scalar replay. It must freeze
its target order, caps and hash manifest before timing.

## Analysis input and acceptance

Input is the immutable order-229 `RUN_V1.jsonl` and `REPLAY_V1.json` from
`../different_j_order_batch_20261015/`. The native analyzer checks record
hash, 84 distinct arm-round-prefix keys, verified outputs, replay status and
the published total of 1,785 scalar checks. It emits one row per child,
paired ratios only for matching prefix and round, a table, and an SVG from
the checked rows. A mismatched digest or missing counter fails closed. The
three elementary portable axes and memory are observations; pricing the
remaining work requires a separate implementation and admission gate.

For later performance: commit exact source, binary and public-input hashes;
interleave the seven arms on a reserved whole core with A/A control; record
isolation earned, clocks, RSS and process output; independently replay on a
different host class. L0 measurements stay descriptive. An L2-or-better
same-host paired run and an independent host performance session are separate
gates. Compare full cold and genuine N-target amortized totals; do not use
amortized cost to claim a one-target gain. Four checked order cells are the
minimum for a descriptive log-log slope, with an interval needed for an
exponent claim.

## Decision rules

- If all three portable axes of one arm exceed a control on every matched
  child, record arithmetic dominance at those orders and leave nonarithmetic
  cost and wall claims separate.
- If axes trade, pin a conversion and uncertainty before any single-number
  ranking. If an arm beats direct rho on **complete** portable `S`, verify
  all terms, replay every scalar and require isolated A/A-admitted timing
  before proposing a frontier change.
- If the screen finds additional orders, audit map and fibers independently,
  then freeze and run the full comparison. A bounded miss changes only this
  family and range. Neither outcome settles the direct chi resultant or the
  pairing-transfer route.

No test result in this protocol is a planned result. Raw failures and earlier
versions remain retained. This V1 protocol is immutable after the first run.
