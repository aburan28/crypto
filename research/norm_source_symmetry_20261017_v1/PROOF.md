# Exact S5 norm-source representatives and complete restoration

This optional reduction applies to the symmetric five-source norm predicate only, with the SAME source domain for all five coordinates. Different source domains require a separate domain-preserving symmetry proof. It does not automatically apply to an arbitrary polynomial or to the original auxiliary S3 chain. Five coordinate roots enter the norm predicate exclusively through the coefficients of H(X)=product(X+x_i). A source permutation leaves H,r and the kernel selector unchanged, hence leaves reconstructed h,k,s and the literal norm condition unchanged.

Choose the canonical nondecreasing order of the five canonical field/domain coordinates. Each norm-primary orbit contains exactly one sorted representative. For each such representative, enumerate all UNIQUE lexicographic permutations of its multiset, retaining the same r and kernel bit. Sorting and restoration are inverse on complete primary model sets. Repeated and zero sources are retained. Orbit cardinality is5!/product(multiplicity!), which can be1,5,10,...,120. Dividing counts uniformly by120 is unsound: all-zero sources have orbit1; four-zero/one-one sources have orbit5.

The field-independent symmetry argument uses only commutativity of polynomial multiplication and a declared total coordinate order. The implementation checks the binary norm model; no odd-characteristic search or original S3 auxiliary restoration is established. Every source permutation needs its own complete auxiliary-fiber reconstruction before original-root completeness can be claimed. A finite-group quotient is classical; no novelty is claimed.

The bounded preparation oracle independently enumerates literal norm roots in small fields, selects sorted representatives, expands unique permutations and requires exact equality of full primary sets. Both target signs, a0/a1, GF4/GF8, zero/repeated sources and two source-domain widths are included. This is a pre-registration correctness oracle, not a hard solve or speed experiment. No original count or speedup follows from smaller representative counts.
