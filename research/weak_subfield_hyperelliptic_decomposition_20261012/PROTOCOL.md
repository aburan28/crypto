# Protocol: is the Bhati–Singh weak-curve decomposition confined to a subfield Jacobian?

Frozen 2026-10-12, before `weak_curve_lab.rs` was run on any input below.
Conductor T-2193. **Structural stage diagnostic on toy fields.** No speedup,
no sub-rho claim, no statement about deployed curves.

## Source

D. Bhati, S. Singh, *A new perspective on the decomposition in the Jacobian
of small genus hyperelliptic curve* (SPACE; CISPA record 104659, figshare
file 66701468, 381137 bytes). Notation follows the paper: `K = F_{q^n}`,
`C/K : y² = f(x)`, `deg f = 5` (genus 2), `K* = <α>`, twist
`f~(x) = f(α^a x)`, `μ~ = α^l`, `ψ = μ~² f~`, factor base
`F~ = {(P) − (∞) : x(P) ∈ F_q}` on `C~`, relations from
`H~ = λ~² − ψ` with `λ~ ∈ F_q[x]`.

## Hypothesis under test (H0, derived, not in the paper)

The paper's condition `ψ ∈ F_q[x]` says `y' = μ~ y` maps `C~` to
`C0 : y'² = ψ(x)`, a curve defined over `F_q`. Then:

- **P1 (collapse).** On a weak curve the subgroup `H` of `J(K)` generated by
  the paper's factor base lies in the image of `J_C0(F_q)` (n odd) or
  `J_C0(F_{q²})` (n even). So `|H|` divides `#J_C0(F_{q^gcd(2,n)})`, and
  `|H| ≤ (1+√q)^{4·gcd(2,n)}` against `#J(K) ≈ q^{2n}`.
- **P2 (control).** On a random curve over the same `K` with the same kind of
  factor base (`x ∈ F_q`), `H` has small index in `J(K)`.
- **P3 (every weak line).** For any affine `F_q`-line `L = βF_q + b ⊂ K` on
  which the curve becomes `F_q`-rational up to a scalar ("weak line"), and for
  the union of all weak lines of a curve, every prime factor of `|H|` is at
  most `(1+√q)^4`. Lines that are not weak give few or no relation candidates
  `(c, λ)` with `λ² − c·f_L ∈ F_q[t]`.
- **P4 (Kani transfer).** For a weak curve whose Jacobian is (2,2)-split,
  `J_C ~ E1 × E2` with `E_i/F_q`, the pullback `E1(K) → J_C(K)` is an
  executable homomorphism, and a point of prime order `ℓ ∤ #J_C0(F_{q²})`
  lands outside `H`.
- **P5 (paper data).** On the paper's Examples 1 and 2, `μ~ · y(P~_i)` lies in
  `F_q` and equals `±λ~(x(P~_i))` for all five published points.

## Falsifiers

- P1 is false if any weak curve below gives `|H|` not dividing
  `#J_C0(F_{q^gcd(2,n)})`, or an element of `H` whose `C0`-model Mumford
  coordinates are not all in `F_{q^gcd(2,n)}`.
- P3 is false if some weak line or union has a prime factor of `|H|` above
  `(1+√q)^4`.
- P4's negative part is false if the transferred point lies in `H`.
- P5 is false if any published point fails the identity.

A falsified P1 or P3 means the paper's relation step does reach the large
prime-order subgroup and the H0 argument is wrong; that outcome is reported
as such and the Kani route (P4) is then re-opened.

## Frozen inputs

All randomness is a fixed-seed SplitMix64 stream (`seed = 20261012`, one
sub-stream per experiment and field). Fields are built from the
lexicographically first monic degree-n polynomial over `F_q` for which `x`
or a small shift of it is primitive.

| Experiment | Fields `(q, n)` | Curves |
| --- | --- | --- |
| E1 collapse + control | (7,3) (11,3) (13,3) (5,4) (7,4) | 3 weak (`f = β⁵g(x/β)`, random monic squarefree `g ∈ F_q[x]`, random `β`) and 3 random monic squarefree `f ∈ K[x]` per field |
| E2 factor-base lines | (7,3) (11,3) (13,3) (7,4) | first weak curve of E1; lines: the weak line, 3 other scalings `β'F_q`, 3 shifts `βF_q + b`, 3 generic affine, 3 Möbius images of `P¹(F_q)` |
| E3 line census | (7,3) (11,3) (13,3) (5,4) (7,4) (3,4) | weak, random, `x⁵ + c`, `x⁵ + cx` (random `c ∈ K*`); all affine lines |
| E3b multi-form | (3,4) (7,4) (11,5) for `x⁵ + c`; (5,4) (7,4) (13,4) for `x⁵ + cx` | union of all weak scaling lines |
| E4 Kani (2,2) | (7,3) (11,3) (13,3) | first `(a,b,c,r)` in lexicographic order with `S = x⁶+ax⁴+bx²+c` squarefree, `S(r) = 0`, `r ≠ 0` |
| E5 paper data | Examples 1 and 2 as printed | the five points of each |

Subgroups are computed exactly by coset extension with a cap of 1.2·10⁷
elements; a capped run is reported as "≥ cap", not as the full group.
`#J(K)` is computed two ways where both apply (point counts over `K` and
`K²`; `det(1 − π^n)` from the `F_q` L-polynomial) and the two must agree.

## Measures

`|H|`, `#J(K)`, index, largest prime factor of each; number of relation
candidates `(c, λ)` with `deg λ = ⌊deg/2⌋` and `λ² − c·f_L ∈ F_q[t]`
(quintic model for affine lines, sextic for Möbius lines; the two models are
not like-for-like and are tabulated separately); number of weak lines per
curve; for E4, order of the transferred point, homomorphism checks, and
membership in `H`.

## Not measured

The Joux–Vitse/Nagao system solve on non-weak lines beyond the bounded
`(c, λ)` enumeration (constant `μ` only); any timing; any field of
cryptographic size; Kani splittings of degree above 2; the characteristic-2
variant of Section 6.

## Language

Computation is in Rust (`weak_curve_lab.rs`, dependency-free, built with
`rustc -O`). Python only plots recorded values.

`all` already ran the supplementary E4x arm, so its JSONL holds six E4x
records (lines 120-122 repeat lines 117-119 exactly) while its run report
said three completed. That record is kept unedited and its run report
carries a correction note. The tool now excludes `e4x` from `all`; the
corrected run is `20261013T0404Z`, compared line by line with the first run
in the README. E4x stays supplementary (added after E4 was seen). The build
line is now `rustc --edition 2021 -O` (the Language section above says
`rustc -O`). Classification: accounting correction; no measured value
changes.

### Amendment 2, 2026-10-12: the random-control and weak-curve samplers are conditioned

P2 and the Frozen-inputs table say "random monic squarefree" `f`. The
sampler in `weak_curve_lab.rs` (`rand_monic_quintic`) draws every
non-leading coefficient nonzero, both for the random `f in K[x]` controls
(E1, E3) and for the `g in F_q[x]` of the weak curves. The frozen records are
not rerun. Claims about the control population are therefore scoped to
"conditioned (nonzero-coefficient) random quintics"; they say nothing about
quintics with a vanishing coefficient.

### Amendment 3, 2026-10-12: E3b is a post-hoc supplementary experiment

The Frozen-inputs table describes E3b as the union of "all weak scaling
lines". `weak_curve_lab.rs` runs `census(..., false)`, the exhaustive affine
census of E3, so translations are included; for `|K| > 3000` (the fields
(11,5) and (13,4)) the translation is restricted to the single value that
clears the `x^4` coefficient. E3b is labelled post-hoc and supplementary.

### Amendment 4, 2026-10-12: wording of P4 and of the line comparison

P4 says the pullback is "an executable homomorphism". The map `phi` is
not implemented on the fibre `u = r^2` of `E1`, and the lab skips pairs that
meet it. Read P4 as: `phi` is a homomorphism on the tested pairs that avoid
that fibre; the test does not establish totality. P3's remark about lines
that are not weak is read as the observed contrast in candidate counts on
the tested lines (constant `mu`, bounded search), not as an equivalence.

### Amendment 5, 2026-10-12: ICV1 names for the elliptic factors

The elliptic factors `E1`, `E2` of E4/E4x are named by ICV1 slug in the
README (AGENTS.md section 11). `reports/icv1_factors.py` computes them from
the recorded `(a, b, c)`, `q`, `n`, modulus and orders, recounting each
order independently; they are registered in `docs/curves/registry.json`
(model identity only; no EC1 representation).
