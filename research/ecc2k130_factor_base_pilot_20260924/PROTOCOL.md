# Frozen degree-7 factor-base pilot (2026-09-24)

## Question and scope

Does a base selected natively on an isogenous binary curve produce more useful independent two-summand relations per charged cost than an equally sized original base? The proxy is `E: y^2+xy=x^3+1` over `F_(2^21)` with modulus `z^21+z^2+1`. Its trace is `-2795`, order is `2,099,948 = 4*29*43*421`, quadratic-twist order is `2,094,358 = 2*7^3*43*71`, and Frobenius discriminant is `-576,583 = -7^3*41^2`. The degree-7 twist-kernel geometry is a small analogue of the degree-263 oriented transport on ECC2K-130: 7 divides neither the original group order nor the order-421 subgroup. This is a toy experiment, not an ECC2K-130 yield, solver-degree, or DLP speed claim.

## Accounting, comparison and decision

Report separate phase counters for field setup, kernel search/map construction, base construction/cofactor projection, target generation/transport, pair-table construction, relation search, rank elimination/recovery, and verification. Field multiplications, squarings, inversions and group-add calls are separate native units; nested inversion operations are not counted twice in a synthetic total. Preserve CPU time as a practicality note only. Cold cost includes map construction and the 421-point inverse table where applicable. A warm scenario must name its target batch size and keep setup outside the per-target numerator. Compare equal 16-point useful bases and equal verified target attempts; show attempts to first full rank, relation hit rate, independent row gain, and cold phase costs. A native-base advantage requires a lower measured total cost to the same verified rank on the paired stream, with zero lift discrepancies and no omitted setup. If any variant fails to reach full rank, or if native gain vanishes after setup, report that directly. The transported and pullback controls should have identical hit and rank trajectories to their source bases; any discrepancy is a correctness failure.

The order-421 toy subgroup gives no meaningful rho crossover for ECC2K-130. Do not extrapolate from it, and do not label any stage ratio an end-to-end index-calculus speedup. A follow-up may test multiple disjoint target streams only after this frozen pilot and its negative results are committed.
