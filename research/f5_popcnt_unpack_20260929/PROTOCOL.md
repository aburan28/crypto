# Matrix-F5 POPCNT direct unpack: frozen experiment

## Hypothesis and reference

The qualified n24 degree-4 F5 output path materializes 13,734,979 monomials and spends roughly half the complete call in direct scalar unpack. Each row first counts the set bits of every packed word to reserve its exact term count. The normal x86-64 build has no process-wide `target-cpu=native`; this experiment tests whether compiling that unchanged direct-unpack loop in a runtime-dispatched `popcnt` function lowers the bit-count cost. Hardware POPCNT as a source of gain is a **hypothesis**, not an instruction-count measurement yet. The reference is the current direct scalar unpack in the same release binary, `KIC_F5_POPCNT_UNPACK=0`; the candidate is opt-in with `=1`. It uses the same `u64` column map, term order and direct writes, with no map conversion. Select it only when direct unpack is active, AVX-512 unpack is off, x86-64 POPCNT is available at runtime, and there are at least 4,096 columns; otherwise use the portable reference. Preserve the exact `Vec<F2BoolPoly>` raw and canonical fingerprints and all counted operations.

The source reference is main commit `d1114083390ddcfde9a063fa7187767c7e7b92e9`: `matrix_f5_f2.rs` SHA-256 `bf35680f431ab7ac13a7615d334ec9b060217b84bdde36f03ce00319491d42da`, `gf2_elim.rs` `6fd3f10ef8e681490784c624e703eeb8fa887c5817ec9bdf34844e3f943c7f5c`, benchmark `f4_f2_bench.rs` `d40f9f0c76e5c56c9f4a52596b9edef41f321aa3d70cfb023c4ba21fdde70336`, isolation wrapper `ff59e53fd5566078ad493c8be0d06168699c4fd194bc881d99df19fa20e007ef`. Prior same-source one-thread baselines and exact outputs are archived in merged #998 and the completed #1024 and #1030 experiments. Absolute times from their different hosts are context only; candidate ratios use explicit `=0/1` processes from one binary on the same runner.

## Workload, isolation, and decision

Run all seven F5 cases in `examples/f4_f2_bench.rs`, primary `f5_n24_m24_d4`, seeds `0`, `badc0de1`, `5eed2026`, `f5c02a28`, one and two Rayon threads separately. Hold selective echelon output, fused row count, direct packed rows, branchless AVX2 strip, AVX2 row XOR, Gray-code table reuse and four-table elimination fixed. Disable deferred-above, word batching, AVX-512 unpack and experimental table construction. Per seed and thread count, run one warmup per arm, five A/A reference pairs and five alternating A/B pairs: 22 processes with all seven cases. Preserve every call, failure, timeout, OOM, source/binary hash, CPU/affinity, raw/canonical row fingerprints, rank, terms, columns, row/criterion/build counts, reduction word operations, selected route, exclusive phases and complete-call time. Release unit tests must compare the specialized path with direct scalar unpack on partial words, sparse/dense and odd rows; CI must execute it on a POPCNT-capable x86-64 runner. Keep the portable fallback correct.

Build/test through `tools/isolated_bench.py busy` under one lock. Each timed seed block uses privileged `tools/isolated_bench.py reserve`, all SMT siblings reserved, one CPU left free, runner Rustup environment passed through, ten-second preflight, other-CPU rate at most 0.10, PSI at most 5.0, zero eligible user threads and zero contended samples at a two-second period. Attempt each seed at most three times in order, select the **first** block with reservation success and 22 exact calls independent of timing, and archive every refusal and partial call. If any seed lacks a qualified attempt, speedup is unknown. Do not combine absolute times across hosts.

The candidate advances only if the frozen one-thread primary complete-call paired reference/candidate median is at least 1.05, its exact 3,125-resample bootstrap 95% lower bound exceeds 1.02, no seed or smaller case has a complete-call median below its own A/A minimum, and the two-thread control has no such regression. A passing candidate needs a separately frozen default-on confirmation. A failing candidate has its tested patch, workflow and raw receipts archived and its runtime option removed. The user's further 2× goal requires the frozen primary full-call median and lower bound both above 2.0 with all guards. These are solver-stage measurements, not IC one-target online DLP or rho speedups.
