This is a fixed-policy engineering comparison, not an ECC2K-130 challenge-log claim or an asymptotic exponent claim. The reference is rho with automorphism order `2n`, `KIC_RHO_DP_BITS=4`, 32 walks, normal-basis canonicalization and one batch table per block. ## Target freeze before measurement

The tracked prior inventory is exactly 76 `*.points.jsonl` files and 34,858 point rows in the merged-main tree after #1097. Its canonical sorted `(path, sha256, rows)` JSON has SHA-256 `5dc98a163504b7c24f1ec781c8fbc6fc80a875d300129babff067863a21947fb` (8,216 n37, 13,321 n41 and 13,321 n53 rows). A preparer must rehash each input and reject any unexpected tracked point file before producing v2 Q.

Q selection is deterministic and target-blind. For cell name `nN_LL`, block `b`, and candidate index `j=0,1,...`, take SHA-256 of the UTF-8 string `ecc2k130-disjoint-cold-v2-20261001|nN_LL|b|j`, interpret the digest as a big-endian integer, and reduce modulo that curve's pinned prime subgroup order to obtain `d`. Reject `d=0`; otherwise compute `Q=[d]G` by the Python GF(2^n) group law. Reject Q if its signed-Frobenius orbit occurs in any prior file or any earlier accepted v2 block of the same n. For this binary Koblitz curve, sign preserves x and Frobenius maps x to x², so the orbit key is the minimum integer among `x,x²,...,x^(2^(n-1))` computed in the pinned field. Accept the first L candidates per block in increasing j order, keeping their original candidate indices, and continue until every fixed block is full. This conditions only on input identity, not on compact/rho work or correctness. Store every accepted `(candidate index,d,Q)`, candidate/rejection counts, all point-file hashes, the prior-inventory digest, the preparer hash and this preregistration commit/hash in `FROZEN.json`. Never replace a Q after timing starts. The only input to either measured program is its public-Q point file; known scalars are held in separately versioned replay fixtures.

An independent pre-timing verifier must replay every `[d]G=Q`, all accepted/rejected candidate decisions and the absence of orbit overlaps with prior and newly accepted Q. It must confirm each field, generator, group order and automorphism size. Rust rho and compact outputs must later recover the same scalar for every public Q. The input freeze and receipt must be committed before timed arms run. A local and Linux source/materialization smoke must pass before the one-shot hosted measurement dispatch.

## Correctness, cost and eligibility

The corrected verifier must be committed and exercised on the six preserved n37/L1024 mismatch records from #1097 *before* v2 Q generation. It must verify that the producer's two pinned intermediate x-coordinates arise from one of the three pairings of the same four independently checked base points, then prove each selected point's signed-orbit label, the four-point group sum, full-rank modular solve, and `[recovered]G=Q`. It may not replace the first run's frozen verifier or receipt. Both compact arms must agree on base hash, rank logs, recovered scalars and other deterministic counters within each block. Every rho scalar is independently checked by group law.

Time with `tools/isolated_bench.py reserve` after its quiet-machine and PSI preflight, reserving the target CPU and its SMT sibling, with `taskset` pinning every child, `RAYON_NUM_THREADS=1`, no concurrent local build, a 900-second/5-GiB arm cap and a 90-minute cell cap. The monitor's `left_on_reserved.user_threads` remains archived as a host limitation, but mere affinity permission is **not** classified as measured contention. Before seeing v2 timing, the native-CPU eligibility rule is: all children succeed; every rank, relation label and scalar passes hosted and separate-host replay; the monitor records zero `contended_samples` under its fixed 0.10-other-CPU threshold with successful quiet/PSI preflight; and the compact B/A median lies in `[0.90,1.10]` with the two-sided 95% log-ratio t interval containing 1. This follows the repository's measured-contention rule in `AGENTS.md` and does not change the archived v1 decision. Record host CPU model, reserved logical CPUs, compiler/tool versions, source/binary hashes, Linux `wait4` user+system CPU, RSS, monitor samples and complete raw output. Wall time is descriptive only because the 0.2-second child polling coarsens short arms.

For each block, the complete compact CPU is `sqrt(CPU_ic_a * CPU_ic_b)` and its paired ratio is that cost divided by the same-block rho CPU. Compute the median and two-sided 95% log-ratio t interval across all 20 or five preregistered blocks; use t critical values 2.093024054408263 and 2.7764451051977987, respectively. An eligible interval wholly above 1 is a quantitative fixed-policy CPU no-go at that cell; six such eligible cells close these tested W64 policies, not all index-calculus routes. An interval touching 1 is unresolved. Any failed replay, resource cap, drift failure or observed contention censors that cell; do not choose replacement Q, rerun a favorable subset or impute a ratio.
