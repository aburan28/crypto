## Hypothesis and fixed source

A separate candidate will express exactly the same five disjoint branches for any nonsingular ordinary binary curve `E_(a,b): y²+xy=x³+a x²+b` over the same polynomial-basis field, requiring canonical infinity `(o,x,y)=(1,0,0)`, exact on-curve inputs and output, and an existential slope only in the doubling and different-x branches. Require `0<=a,b<2^n` and `b!=0`. The curve equation adds `a*x²+b`; the doubling and different-x output abscissae each add `a`. All other full-point conditions, input order, limb validation, and branch equations remain as in the source DAG. ## Frozen correctness panel

After candidate and independent verifier source are committed and SHA-256 frozen in a separate manifest, run one bounded panel. For `(n,f)=(2,0x7),(3,0xb)`, take `a` in `{0,1}` and every nonzero `b` in the field. Enumerate every canonical rational point, including O, and every ordered `(P,Q,R,lambda)` in the field. The DAG must accept exactly when `R=P+Q` under an independently implemented polynomial-basis group law. For each valid `(P,Q,R)`, the accepted-slope count must be `2^n` in copy and inverse branches, one in double and different-x branches, and zero for a wrong `R`. Enumerate every noncanonical or off-curve point encoding in each of the three point roles with the other roles O and every slope; all must reject. Check all five branches occur in the panel. Reject zero `b`, out-of-range coefficients, malformed model limbs, omitted limbs, and nonzero padding.

For each exact degree-263 leaf, use archived native points 0 and 2 (distinct x) as `P,Q`. Test O+P, P+O, P+(-P), P+P, P+Q, and the unique x=0 point T with T+T=O. Compute the reference result and, where needed, the unique slope from an independent field implementation; check the correct full point and a deterministic wrong archived native result, as well as a wrong slope in slope branches. Test canonical infinity and one deterministically chosen off-curve encoding. Check the archived native points and computed T satisfy the literal leaf equation, and verify the archived exact replay is PASS. These exact-leaf controls exercise actual `b` values but do not prove m≥3 factor-domain or solver capacity.

The producer archives compact per-curve counts and a SHA-256 stream of every small-field truth-table row, exact-leaf branch/control rows, node/limb counts, first mismatch, CPU, wall, RSS, source/input hashes, and failures. An independent verifier recomputes the group-law reference with separate bit-polynomial arithmetic and checks the raw rows and all exact-leaf cases. Cap each child at 600 wall seconds and 1 GiB peak RSS; timeout, OOM, missing raw rows, or a verifier mismatch is STOP/FAIL, never a negative PDP result. Do not overwrite a failed archive. Commit the frozen source/input manifest **before** this panel, then commit raw evidence, verifier receipt, and a decision in the same PR. CI must replay the archived checks.

A PASS establishes only that the generic full-point *addition edge* can model the two saved degree-263 leaves and exceptional inputs. The subsequent admission requires binding m≥3 implicit native factor domains, exporting an exact SAT/ANF instance, lifting every positive model to a labelled point sum, distinguishing proved UNSAT from unknown/resource exits, and passing the necessary physical-support/rank screen. Keep common-unit full-DLP cost, n131 crossover, and matched-rho speedup unset here.
