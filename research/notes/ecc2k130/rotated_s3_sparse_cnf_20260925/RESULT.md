# Sparse O-aware recursive-S3 CNF: exact toy semantics pass, solver comparison next

[PR #786](https://github.com/aburan28/crypto/pull/786) passes the frozen representation gate against merged [#781](https://github.com/aburan28/crypto/pull/781). A Sinz sequential exactly-one block plus one allowed-output implication per transition input pair preserves the complete rational signed-point path and target semantics on all four fixed panels. The independent verifier parsed both DIMACS formulas, reconstructed the dense allowed table from its actual forbidden triples, reconstructed the sparse table from its actual implications, computed the local table again from signed point addition, and enumerated all 24,955 primary-state paths against 56,394 signed factor tuples and 61 exact target assumptions. There were zero path, terminal-sign or target mismatches. The n13 `Q3T0=(7256,3272)` exceptional-only `[0,0,0,2,1]` factor mask still passes through O; the n13 O target remains genuinely empty in both CNFs and the full-point oracle.

The preregistered n13 2,517-variable/4,731-clause forecast and 250,000-byte cap passed. Sparse/dense n13 clauses are 0.3958% and raw bytes 0.3980%, roughly 252.7× and 251.3× smaller respectively; variables nearly double because the 1,254 sequential auxiliaries follow the 1,263 unchanged primary literals. The fixed n13 schema has 969 input pairs: 636 permit two admitted output states, 330 permit one, and **three permit none**. Those three are unreachable `S3=O` / F3 x in `{0,257,6433}` pairs with no admitted S4 value. Each sparse binary `(-u,-a)` ban equals #781's all-forbidden-output triples under exactly-one S4. Full paths do not visit them, but local equivalence and the explicit mutation control check them.

All five corruption controls rejected their intended defect: forbidding `(0,0)→O`, changing that O output to finite x=0, dropping a sequential AMO clause (with a demonstrated two-hot local witness), changing the O target assumption to finite x=0, and adding a false S4 output to one n13 binary pair ban. The last control writes a raw mutated DIMACS file and the independent parsed point-law check rejects the pair `(S3=O,F3=0)`. The frozen #781 dense rerun also passed its inherited nonlift and sign-incomplete input controls. Every final output stays under the 180 s / 512 MiB per-child limits; the 195 s external stop did not fire.

The sparse replay is **3.65× slower by external wall** than the dense replay because this new verifier checks two parsed CNFs, all sequential blocks, every path's clause truth and an extra mutation. Its lower RSS and the smaller DIMACS are useful representation diagnostics, not measured SAT speed. The run used one fixed dense-then-sparse order and did not control cache effects. No solver, full-DLP search, n131 transfer or rho comparison was run here.

**Decision:** accept this as a smaller, branch-complete **toy** CNF representation and as an engineering result against #781's dense baseline. A separate, preregistered same-32-target SAT comparison can now measure actual cold solver behavior and independently lift returned models. An n19 explicit-state feasibility gate should first cap and report every prefix-state group and relation-table growth; even a passing n19 table cannot justify an n131 explicit table. A symbolic multiword recursive-S3 representation with O/inverse flags and independent model lifting remains the n131-oriented direction. Direct S6/S7 equivalence, checked solver UNSAT proofs, rank/yield, full ECDLP cost and any crossover remain open.
