## Fixed semantic input and formula

The four panels and every factor x, prefix state, exact target point and Q+T label are exactly #781's `n2-m4`, `n3-m5`, `n4-m4`, `n13-m5` schemas. The n13 panel retains all 32 fixed Q+T points and O, including target index 12 `Q3T0=(7256,3272)` and its exceptional-only mask `[0,0,0,2,1]`. `FROZEN.json` pins #781's base DIMACS, schema and compressed full-path bytes separately for each panel, plus the #781 producer, verifier and result sources. No x domain, sign fibre, path, target, order or field polynomial may change. All domains have complete rational signed point fibres. #781's O-prefix, O-terminal, inverse, x=0 and doubling semantics are retained.

The primary literals keep #781's group order and numbers: factor groups `F0...` and prefix groups `S2...`, with one selected value per group. For each group of size k, add one at-least-one clause and the fixed Sinz sequential at-most-one encoding with k-1 fresh auxiliary literals, numbered contiguously after every primary literal in group order. For k=1, add only its unit at-least-one clause. For k>=2, the exact clause order is `(-x1,s1)`, for each `i=2..k-1`: `(-xi,si),(-s(i-1),si),(-xi,-s(i-1))`, then `(-xk,-s(k-1))`. Thus the one-hot clause count is `1` for k=1 and `3k-3` for k>=2, with k-1 auxiliaries. Each one-hot primary choice has exactly one satisfying auxiliary extension: `sj` is true iff the selected index is at most j. The block rejects zero- or multi-hot primary choices.

For each input pair `(u,a)` in each #781 stage, emit exactly one allowed-output implication, in schema order: `(-literal(u),-literal(a),literal(v1),...,literal(vt))` where permitted output states are the complete rational S3/O transition set, in the output group's value order. The producer computes finite roots using #781's pinned bit-serial field module and adds `O` iff the two finite x values are equal; `O+a` has only finite output `a`. The output list is the intersection of mathematical rational transitions with the frozen admitted output group. If that intersection is empty, the clause is exactly the binary pair ban `(-u,-a)`. The retained first attempt exposed three such n13 input pairs: unreachable admitted `S3=O` with F3 x in `{0,257,6433}` has no admitted S4 output. Their dense reference forbids every S4 value, which is equivalent to the binary ban under exactly-one S4. The corrected n13 run must record exactly three empty-output pair clauses; all other panels must record zero. The independent verifier does not call that producer transition code: it derives permitted states from full signed point addition. Since the output group is exactly one-hot, the implication is equivalent to selecting one permitted output. Each target assumption remains #781's final primary-state literal, including O; auxiliary literals are never target assumptions.

The deterministic n13 structural forecast from frozen #781 schema is nine groups of sizes `3,3,3,3,3,13,60,247,928`, hence 1,254 auxiliaries and 3,762 sequential one-hot clauses. The observed schema has 969 stage input pairs; therefore the preregistered expected sparse n13 count is 4,731 clauses and 2,517 variables. This is a **source-structure forecast**, not a measured sparse outcome. A different count is a failed gate and retained evidence.

## Independent exhaustive replay and negative controls

The verifier parses the emitted sparse DIMACS and checks its exact clause sequence, variable ranges, auxiliary numbering, one-hot blocks and target assumptions. It independently parses the frozen dense DIMACS stream, checks its pairwise one-hot clauses, and recovers its allowed output table as the complement of its actual forbidden triples. For each local input pair, including any binary pair ban, it compares (1) the parsed sparse implication, (2) the parsed dense transition table and (3) a separate full signed-point group-law table. It never imports the sparse producer transition function. It verifies the sequential one-hot truth table exhaustively for every group of size at most five; for larger groups it checks the exact fixed encoding and its algebraic invariant.

For every factor-x tuple in all four panels, the verifier enumerates the complete sparse CNF primary path set from the parsed implication table. It compares the ordered full path list with #781's SHA-fixed dense path archive and with every full signed-factor tuple recomputed using #762's independent field/group law. It checks both terminal signs, all target assumptions including O, and the n13 exceptional witness. Auxiliary assignments are not counted as independent paths. Full Boolean truth-table enumeration over 2^2517 assignments is not attempted; the exact one-hot block proof and complete selected-path enumeration give the same primary-variable semantics.

Negative controls must reject (a) an appended clause forbidding the n2 `(0,0)->O` branch, (b) a changed allowed-output implication that replaces that O output by finite x=0, (c) a removed sequential AMO clause, (d) an O target assumption changed to finite x=0, and (e) a mutated n13 binary empty-output ban that adds an admitted S4 output. The fifth control writes its exact mutated CNF and must fail the parsed-CNF/independent-point-law check for that input pair. Controls record separate first-failure classes. #781's nonlift and sign-incomplete input controls remain inherited through frozen #781 validation, not remeasured here.
