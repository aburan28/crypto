# ECC2K-130 index-calculus decision ladder (2026-09-25)

This is the current execution order after the exact compact-orbit and rotated
factor-base experiments. It supersedes the *uncompleted-gate descriptions* in
[the earlier decision note](NEXT_EXPERIMENT_DECISIONS_20260925.md), whose
preregistered protocols and historical measurements remain valid. The
[canonical scoreboard](../../../docs/index-calculus-scoreboard.html) holds

independent replay, raw failure receipts and a merged PR under
[AGENTS.md](../../../AGENTS.md). Stage coverage, solver time, and a correct
full logarithm are different outcomes.

## Next experiment gates, in order

1. **Compress the branch-complete encoding and validate a direct arm.** #777 proves the rational finite-fibre theorem; #781 independently validates an O-aware recursive-chain CNF against every signed tuple on three full toy fields and all fixed n13 Q+T point labels. The dense forbidden-triple/one-hot layout reaches 1,195,344 clauses at n13, so freeze a sparse allowed-transition or selector encoding on the identical labels, prove it equivalent to #781, and keep O/inverse/x=0 branches explicit. Separately build a direct S6/S7 encoding of the same frozen #767 positive/negative full-point targets and verify every returned model by the point oracle. A complete negative proof requires a checked full model search; an over-cap search is unknown, never UNSAT. These gates must pass before relative Gray/FES/crossbred/SAT/Gröbner timing is interpreted.

2. **Admit solvers on one fixed system, then compare.** [The admission matrix](ROTATED_M5_M6_SOLVER_ADMISSION_20260925.md) records each current interface and its width limit. Existing in-crate Boolean monomials and model lifting use a u64 mask; the direct n131 m5/m6 factor bits alone are 125/126, and raw S3-chain variables are 518/650 before extras. Exporters, parsers and exact model checks must therefore support the actual width rather than silently truncate. Pin binary/version, direct or chain system, equation and variable order, CNF versus native XOR, threads, seeds, 15 s/2 GiB pilot caps, and exit/model/UNSAT semantics for each admitted arm. Compare a first valid witness on positives and a complete certified refutation on negatives separately. WDSat's corrected child-status handling in [#764](https://github.com/aburan28/crypto/pull/764) is necessary but does not supply its missing multiword exporter. CryptoMiniSat, MiniSat, msolve, F4/F5, FES and crossbred are candidates only after their input and output gates exist.

3. **Compare the two admitted m10 arity layouts in an implicit-PDP feasibility protocol.** Once the branch-complete point semantics and an admitted solver interface exist, freeze the same target stream, valid/negative criteria, memory cap and total work accounting for balanced m10,d13 and unequal m10 (one 14-bit plus nine 13-bit slots). The former has 3,988 signed nonzero columns and 1,178 raw chain variables; the latter has 8,062 and 1,179. Separate relation acquisition, independent rank, target descent and unsuccessful searches. A tuple count above q cannot stand in for a hit rate, rank or speed. m9 missed the frozen column cap by only 239, but may enter a later cost/Pareto study only under a fresh preregistered gate.

4. **Charge an actual PDP for the four-base portfolio.** #779 closed the archive-oracle joint-rank/holdout gate on the #775-selected `[3,338435,303097,464276]` bases: rank 12/12 and 58/64 verified logs versus beta-3 rank 3/3 and 29/64 on the same unconditional Q stream. Once Gate 2 admits a branch-complete solver, repeat the paired comparison with cold base construction, relation search and every failed/negative query included. Compare to an automorphism-aware matched batched rho over the identical Q block. The four-base route advances only if it lowers **total** charged work at a larger rung; if setup or negative search absorbs the toy coverage gain, stop portfolio expansion.

5. **Use a cost-aware easier-PDP policy only after measured per-instance cost exists.** A target trace or cofactor class that is constant within the prime subgroup cannot rank its nonzero Q instances. Candidate features must vary on same-subgroup targets, be computable without solving the PDP, and be charged. Freeze training/held-out streams and an abstention rule before choosing base order or solver. Compare total verified-log cost, including skipped targets, false negatives and all failed probes, against the fixed #775 order. A supported-target classifier is not automatically a fast decomposition algorithm.

6. **Only then test n131 and the degree-263 leaf end to end.** Price any admitted implicit exporter and solver, factor-base construction, independent full relation rank, sparse linear algebra, target descent, Q verification and maps. Use the literal #771 challenge fixture for a bounded smoke; use smaller fully solvable rungs for a cold full-log comparison against same-Q automorphism-aware batched rho. Reopen a descendant-native arm only under the matched-size/action admission above. A solver phase or relation count alone cannot establish an ECC2K-130 crossover.

The active Codex goal is achieved only by a reproducible end-to-end crossover
with explicit n131 transfer assumptions, or a quantitative no-go for these
routes with the next evidence-ranked direction. It is still active. The
public challenge logarithm has not been recovered.
