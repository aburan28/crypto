# ECC2K-130 index-calculus decision ladder (2026-09-25)

This is the current execution order after the exact compact-orbit and rotated
factor-base experiments. It supersedes the *uncompleted-gate descriptions* in
[the earlier decision note](NEXT_EXPERIMENT_DECISIONS_20260925.md), whose
preregistered protocols and historical measurements remain valid. The
[canonical scoreboard](../../../docs/index-calculus-scoreboard.html) holds
the numerical ledger. Every new experiment below gets a frozen protocol,
independent replay, raw failure receipts and a merged PR under
[AGENTS.md](../../../AGENTS.md). Stage coverage, solver time, and a correct
full logarithm are different outcomes.

## Next experiment gates, in order

1. **Finish the exact n131 F0 cardinality census.** Draft [#773](https://github.com/aburan28/crypto/pull/773) froze beta 3, m6,d21 and a two-stage Gray-code/independent polynomial-division replay. Accept only a complete all-2,097,152-mask replay matching rational-lift, projected signed-column and chunk digests. Record the actual nonzero signed-column count, physical point count, setup and high-water resources. The frozen pilot is a prefix check, not a density estimate. If the full verifier disagrees or caps out, retain that failure and leave n131 cardinality unknown. After acceptance, replace the nominal `2^21` column proxy with the measured C in every subsequent row-rank and cost budget; do **not** infer target support or rank from C alone.

2. **Encode a branch-complete PDP semantics.** #777 proves that finite S3 roots on sign-complete rational x fibres are rational signed sums, including x=0, repeated x, doubling and inverse-to-O; O prefixes remain separate states. Build a direct S6/S7 and a recursive chain encoding of the same frozen #767 positive/negative full-point targets, with every returned model independently lifted and the O-prefix witness reproduced. The gate is exact agreement with the complete signed-point oracle on all fixed labels, including certified negatives; an over-cap search is unknown, never UNSAT. This gate must pass before any relative Gray/FES/crossbred/SAT/Gröbner timing is interpreted.

3. **Admit solvers on one fixed system, then compare.** [The admission matrix](ROTATED_M5_M6_SOLVER_ADMISSION_20260925.md) records each current interface and its width limit. Existing in-crate Boolean monomials and model lifting use a u64 mask; the direct n131 m5/m6 factor bits alone are 125/126, and raw S3-chain variables are 518/650 before extras. Exporters, parsers and exact model checks must therefore support the actual width rather than silently truncate. Pin binary/version, direct or chain system, equation and variable order, CNF versus native XOR, threads, seeds, 15 s/2 GiB pilot caps, and exit/model/UNSAT semantics for each admitted arm. Compare a first valid witness on positives and a complete certified refutation on negatives separately. WDSat's corrected child-status handling in [#764](https://github.com/aburan28/crypto/pull/764) is necessary but does not supply its missing multiword exporter. CryptoMiniSat, MiniSat, msolve, F4/F5, FES and crossbred are candidates only after their input and output gates exist.

4. **Charge the four-base portfolio.** Use #775's protocol-selected `[3,338435,303097,464276]`, the beta-3 single-base control and the same disjoint SHA-selected n19 Q stream. Count unique cross-base signed columns, independent modular rank, rows and misses needed to train them, and same-Q point-only recoveries. An archive-witness lookup is explicitly an oracle-stage diagnostic; it does not price a PDP solver. Once Gate 3 admits a branch-complete solver, repeat with cold base construction, relation search and every negative query included. Compare to an automorphism-aware matched batched rho over the identical Q block. The four-base route advances only if it lowers **total** charged work at a larger rung as well as crossing the toy support gate; if rank/setup/negative search absorbs the coverage gain, stop portfolio expansion.

5. **Use a cost-aware easier-PDP policy only after measured per-instance cost exists.** A target trace or cofactor class that is constant within the prime subgroup cannot rank its nonzero Q instances. Candidate features must vary on same-subgroup targets, be computable without solving the PDP, and be charged. Freeze training/held-out streams and an abstention rule before choosing base order or solver. Compare total verified-log cost, including skipped targets, false negatives and all failed probes, against the fixed #775 order. A supported-target classifier is not automatically a fast decomposition algorithm.

6. **Only then test n131 and the degree-263 leaf end to end.** Price the implicit m5/m6 exporter and solver, factor-base construction, independent full relation rank, sparse linear algebra, target descent, Q verification and maps. Use the literal #771 challenge fixture for a bounded smoke; use smaller fully solvable rungs for a cold full-log comparison against same-Q automorphism-aware batched rho. Reopen a descendant-native arm only under the matched-size/action admission above. A solver phase or relation count alone cannot establish an ECC2K-130 crossover.

The active Codex goal is achieved only by a reproducible end-to-end crossover
with explicit n131 transfer assumptions, or a quantitative no-go for these
routes with the next evidence-ranked direction. It is still active. The
public challenge logarithm has not been recovered.
