The larger-stack log records the archived n=37 compact-orbit source42 test and the million-store test as passing. Five `curve_traits` tests fail because the current registry includes the `B*y^2=x^3+A*x^2+x` model form, which the unchanged `curve_traits::parse_model` rejects; an isolated `a_small_koblitz_curve` rerun reproduces the parser error. The `ecbench::record` legacy-float test independently fails its bit inequality. Other recorded failures include wide n=71 arithmetic, Cairn and peer-network tests, and frozen CryptoPro chain tests. The complete list of failed test names is in the compressed audit log. A separate exact run of `ec_index_calculus_j0::staged_dlp_recovers_and_splits_stages` passed after it had failed in the four-thread audit, so that test needs isolated rerun conditions before attributing a cause.

For the changed example, `cargo build --offline --release --example koblitz_orbit_dlp_fast` passed, `cargo test --offline --release --example koblitz_orbit_dlp_fast` passed 3/3, and the independent rank and target replay receipts in this directory both report `PASS`. These targeted checks establish the repaired producer path; the release library suite remains unresolved on this parent.
