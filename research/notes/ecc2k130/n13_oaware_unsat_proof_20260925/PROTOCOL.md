# Frozen protocol: external DRAT checks for fixed n13 O-aware PDP negatives

Status: preregistered before any proof-generation run on the selected #785 toy queries. This experiment starts from merged [PR #785](https://github.com/aburan28/crypto/pull/785) at `91eb1567ab6d02f4af4e090ff091c7b6e0d1adff`, independently of the pending unequal-arity PR #784. The literal parent freeze, panel, CNF, schema, checker source, protocol and program hashes are pinned in `INPUT.json` and `FROZEN.json`. Open a draft PR and pass hash-only CI before measuring any selected negative. A corrected pre-outcome checker-control assertion and its first failure are retained in [PREOUTCOME_PREFLIGHT_FAILURE.md](PREOUTCOME_PREFLIGHT_FAILURE.md).

## Fixed full-point queries and semantic limit

Reuse #781's exact n=13,m=5 O-aware rational point-sum CNF and #785's query construction: replace the base DIMACS header's clause count with one additional clause and append the selected positive assumption literal. The frozen branch order is `Q0T0` (literal 676), then `Q4T0..T3` (literals 629,504,985,690). Their complete #767 point oracle labels and #785 CaDiCaL statuses are negative. `Q0T0` is a negative torsion branch of a projected-positive Q; `Q4T0..T3` are all four branches of one projected-negative Q. The fixed positive `Q0T3` (literal 596) is used only as a wrong-input rejection control. Reconstruct and SHA-check every query against #785's independently archived query hash before solving. Do not choose or substitute branches after seeing a proof result.

Use the exact local CaDiCaL 3.0.1 binary SHA-256 pinned in `INPUT.json`, with `--no-binary`, positional input CNF and positional text DRAT proof path. Require exit 20 and `s UNSATISFIABLE`, then verify the resulting proof with a **separate** DRAT-trim implementation, not CaDiCaL's internal `--checkproof`. The checker is vendored under `checker/` from upstream commit `2e3b2dc0ecf938addbd779d42877b6ed69d9a985` (MIT license); source SHA-256 and the local Mac build recipe/binary SHA-256 are pinned. The runner checks that binary hash; archive replay recompiles the pinned source independently, allowing a platform-specific binary hash to be recorded without assuming identical Mac/Linux binaries.

The pre-outcome checker control is a fixed non-unit two-variable XOR contradiction. The checker must accept its explicit DRAT proof and **reject its mutated copy with both derived unit steps removed while retaining the claimed empty clause**. After generating the first target proof, the same proof must be rejected against the frozen SAT query `Q0T3`. This cross-input control checks that a target proof cannot be detached from its exact assumption CNF. An actual negative is admitted only when the external checker returns zero and `s VERIFIED` on the reconstructed query/proof. A solver status, agreement with an exhaustive point oracle, or CaDiCaL internal checking alone is insufficient.

## Bounds, archive, and decision

The five cases run in fixed order as cold solver and checker children. Each solver has a 60-second wall cap, each checker and the cross-input check has a 180-second wall cap, with 15-second runner grace; every child has a 1-GiB recorded RSS upper-bound cap. A raw proof must be nonempty and at most 128 MiB before checker admission; the complete archived output directory is capped at 512 MiB and the temporary query/proof workspace at 320 MiB. Raw completed proofs other than Q0T0 are removed from the temporary workspace only after their deterministic gzip copy and external check are recorded; Q0T0 is retained until the wrong-input control completes. Record proof generation wall/CPU/RSS separately from external check wall/CPU/RSS, and retain exact commands, versions, source/input/binary hashes, query hashes, raw proof byte count and SHA-256, deterministic gzip proof, stdout/stderr, UTC intervals, exit/status and any failed/censored attempts. Use a unique output directory; never replace the first receipt. Archive-only CI must reconstruct each exact query from the pinned base and literal, decompress every committed proof, rerun the externally compiled checker, and repeat the valid/mutated and wrong-input controls.

The gate passes only if all five negative branches have independently checked proofs, all controls behave as frozen, and all caps and hashes pass. Then the fixed O-aware CNF has checked UNSAT certificates for those five full-point Q+T queries; because all four Q4 torsion branches are included, Q4 is projected-negative **within this toy CNF**, supported separately by #781's complete toy semantic replay. A proof here does not certify arbitrary PDP encodings, n19/n131 systems, all #785 negatives, solver superiority, a Certicom log, full index-calculus cost or rho speed. If any proof is missing, over cap, invalid or uncheckable, report that branch unknown under this protocol, preserve its first evidence, and make no projected-negative proof claim.
