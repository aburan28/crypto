# Frozen near-threshold n19 slot-placement test

Status: **factor-only preflight; no six-sum outcome has been computed.** This
is a separate follow-on to [PR #793](https://github.com/aburan28/crypto/pull/793),
whose full-rank 19-coordinate slots saturated every subgroup target. It
uses the older unsaturated beta-3, n19 rank-two frame from
[#767](https://github.com/aburan28/crypto/pull/767), with one fixed unused
normal conjugate added to exactly one slot. #769 varies the normal generator
at rank two and #775 combines several such bases; neither measures this
coordinate placement. PR #793's observed support does not enter selection,
thresholds or target membership decisions here.

## Fixed model, factor-only preflight, and dependency

Use `E: y²+xy=x³+1` over `F2[x]/(x^19+x^5+x²+x+1)`, subgroup
`q=130873`, and beta `3`. Let `b_j=beta^(2^j)` for `j=0..18`.
In every arm, slot `i=0..5` contains `span(b_i,b_(i+6))`; the one
additional normal conjugate is always `b_18`, assigned to one predeclared
position `p=0,1,2,3,4,5`. The joint rank is 13 in every arm, leaving six
normal coordinates unused. Enumerate all rational affine lifts of each
slot's x-subspace, both signs where present, with no infinity factor.
The six positions and b18 are immutable; do not substitute a more
favourable extra coordinate or beta after any tuple-sum outcome.

The versioned [PREFLIGHT.json](PREFLIGHT.json) was generated only from
field/basis arithmetic, single-factor lifts, and single-point `[4]`
projections. The separate bit-serial/Fermat
[verifier](verify_preflight.py) rebuilt every factor point, slot rank,
signed projected pair and the shared 64 target scalars. Neither program
adds points from different slots or reads a PDP support map. The preflight
SHA-256 is
`a839634a27bba330f448e2d45867c54d3f2f09c5932c85360ca6412cc5966369`.

## Complete exact census and fixed decision

After the above gates, enumerate the same q subgroup points `kH` under
#767's frozen generator rule. Map every labelled factor point `[4]P` to
its exact scalar and cyclically convolve all six factor choices. Commit
every arm's complete q-entry little-endian uint32 projected
multiplicity array, including zero entries. Check `sum c_k=N` and report
exact support `K=#(c_k>0)`, misses `q-K`, second moment
`M2=sum_k c_k²`, collision pairs `(M2-N)/2`, and Cauchy's proven support
floor `N²/M2`. The already-reported n19 rank-two moment from #769 is a
different-budget reference, not a new formula or positional result.

Use exactly the same 64 nonzero Q scalars as #793, generated by its
SHA-256 target-domain rule and pinned in `PREFLIGHT.json`; all six arms
receive those same labels. For every supported sample, archive one
deterministic predecessor witness, check its full curve sum projects to
`kH`, produce a signed column row, verify its scalar identity, and measure
mod-q rank of the 64 sampled first-witness rows. An unsupported sample
has no row. This rank is an archive-oracle diagnostic, not independent
relation collection, implicit PDP solving or an n131 rank prediction.

For all 15 position pairs report the exact all-q support intersection,
symmetric difference, N/B match, 64-label flips, M2 and sampled rank.
The frozen follow-up gate passes only if **an equal-(N,B) pair** has both
`|K_a-K_b|>=1309` (at least 1% of q) and support symmetric difference
`>=2618` (at least 2% of q), with both arrays independently replayed.
If no equal-budget pair meets both, retire b18 placement as a support
lever at this rung; do not pick another coordinate or lower a threshold.
The counting ceiling `K<=min(q,N)` is a bound, not a predicted hit rate.
There is no n131 transfer from this small curve.

## Independent replay, caps, accounting, and PR result

The producer uses #762's extended-Euclid field/group implementation
and a sparse-support cyclic convolution with predecessor witnesses. The
independent verifier uses #767's separate bit-serial/Fermat arithmetic,
rebuilds factors and all q subgroup labels, traverses dense scalar
indices, compares every multiplicity byte, checks each of the 64 shared
target witnesses and independently computes modular row rank. Source,
input, preflight, workflow and parent hashes are fail-closed. Each
producer/verify child has a 300/600-second wall cap and 512-MiB peak-RSS
gate, with a 30-second external timeout margin. Preserve all children,
including failures, stdout/stderr, resource and hash receipts, exact arrays
and the final decision. Charge all group setup, factor lifts, q-point
map, convolution, target rows and independent replay; wall is a host
diagnostic. A later result PR commit must also update the canonical
scoreboard. Solver cost, negative PDP proof cost, full IC `S`, matched rho,
and the ECC2K-130 challenge logarithm remain unset.

The current draft commit contains only protocol, complete factor-only
preflight, frozen source, input and hash-only workflow. It has no support
result, scorecard verdict, or speed claim. Its six-sum runner must stay idle
until the parent-merge and review gates above are met.
