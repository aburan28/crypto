# Compact-orbit rank trace: fixed control passed

The exact-source n=13 control produced two rank-stage attempts, two group-law relations and rank 2/2. Independent Python arithmetic reconstructed both `[a]G − R_j` targets, all four base points in each witness, their x-codes and pair intermediates, both modular rows and rank transitions, the solved orbit logs `[1,1834]`, and `[L_j]G=R_j` for both representatives. Seven distinct used base points passed subgroup-order and orbit-label checks. The single target scalar `7` was independently recovered and checked as `[7]G=Q`. With `KIC_DUMP_RANK` unset, the producer returned the same deterministic base, rank and target outputs; only timing and RSS fields are excluded from that equality check.

The write-once [raw local control](evidence/local_control_20260929/receipt.json) and [manifest](evidence/MANIFEST.json) retain both process commands, the source commit, binary digest, stdout/stderr, base headers, target records, trace, and replay. The manifest SHA-256 is `a61a96aeba70d081e4d0b23c4249533b86fb326215ab39a1d87802eafb34e311`. The replay explicitly labels missed-search nonexistence unproved; this control happened to have zero misses. Mutation controls reject a wrong full-point target, matrix row and solved base log. The exact-head [Ubuntu 24.04 CI run 36550847279](https://github.com/aburan28/crypto/actions/runs/36550847279) passed the same build and replay. Its [durable raw copy](evidence/hosted_36550847279/receipt.json) and [manifest](evidence/HOSTED_MANIFEST.json) are committed; the hosted manifest SHA-256 is `605e1a0ad10416e2d48a60c2442ee40a691c1a6d082c5b4b80b188744f73aae9`. This result validates an audit interface, not the historical n=37/41/53 rank stages retroactively. Those earlier runs lacked traces, so their source-reported full rank remains weaker evidence. The next measurement must use the new trace on fresh frozen public-point L=1 and L≥1,024 workloads, independently replay the rank and target relations, and charge setup, failed searches, matrix solving, target queries and the matched automorphism-aware rho process. The n=13 control has no timing claim, rho comparison, or ECC2K-130 transfer claim.
