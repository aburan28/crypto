# Independent full-rank replay for the compact-orbit producer

Status: **pre-outcome verification gate**. The archived fast shared-log panels at n=37/41/53 report full rank and correct target scalars, but `koblitz_orbit_dlp_fast` did not emit the rank-stage attempts or solved orbit logs. This change adds an optional `KIC_DUMP_RANK` JSONL trace. It does not alter base selection, S3 search, row construction, pivot policy, target search, or rho. Its purpose is to let independent arithmetic verify the producer's training stage before a new cold point-only comparison. It is not a speedup or an ECC2K-130 attack result.

The verification hypothesis is falsifiable: for every traced attempt, an independent GF(2^n) group law reconstructs `[a]G - R_j`, checks the reported four-sum witness when present, the x-codes and pinned S3 intermediates, the exact modular row and rank transition; then it independently solves the full-rank matrix and verifies `[L_j]G=R_j` for every representative. A mismatch, absent trace record, dependent row reported as independent, incorrect orbit label, invalid point/order, or wrong final log is a failure. An unsuccessful search is retained as an attempt; the verifier does **not** prove that no decomposition existed for a miss. The result is a rank-certificate validation, not a completeness proof for the extractor.

The fixed integration control is `E_0: y²+xy=x³+1` over GF(2^13), base `construct:13:0:2`, rank seed `7`, and one known-answer scalar `7`. The source/main boundary and source/input SHA-256 digests are in `FROZEN.json`. The test uses `KIC_DUMP_BASE` and `KIC_DUMP_RANK`, archives producer stdout, target record, base header and rank trace, and requires `rank=2`, one verified target scalar, and an independent `PASS` with every attempt and both representative logs checked. The exact number of failed searches is observed, not chosen after the run. This small control checks the trace contract only; it is not a timing or n=37/41/53 result.

The next measured panel should freeze the n=37/41/53 public-point L=1 and L=1,024 streams and disjoint base-size tuning before execution, run one cold full-rank process per arm and target block against the same-Q signed-Frobenius batched rho, and archive every rank trace, target relation, failed query, scalar, setup/rank/LA/query phase, CPU, wall, RSS and source/input hash. A common calibrated operation unit and independent host replication remain necessary for any end-to-end crossover claim. The historical 32-target batch ratios in `autolab_orbit_extract_20260924/RESULT.md` must not be substituted for that panel.
