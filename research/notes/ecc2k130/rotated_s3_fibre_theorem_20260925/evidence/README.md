# Frozen finite-fibre S3 exactness evidence

This directory is the complete first and only run of the preregistered
[protocol](../PROTOCOL.md) at [freeze](../FROZEN.json) SHA-256
`d87bfa84b6d6ccffe859cf044b22cbf0fc901ac71e3d0d01b35469a7760855e3`.
It was produced after draft [PR #777](https://github.com/aburan28/crypto/pull/777)
and its hash-only preflight were green. The recorded command was
`python3 research/notes/ecc2k130/rotated_s3_fibre_theorem_20260925/run.py --out research/notes/ecc2k130/rotated_s3_fibre_theorem_20260925/evidence`.
The receipt records the cold child commands, UTC start/end, exit status,
external timeout status, wall cost, and output hashes. Child JSON records
its own wall/CPU/RSS and native operation counts. Empty stdout/stderr
files are retained as evidence. `MANIFEST.json` records byte counts and
SHA-256 for each committed output; the full compressed raw pair and chain
rows are directly committed, with no external-only dependency.

To audit without repeating the experiment, run
`python3 research/notes/ecc2k130/rotated_s3_fibre_theorem_20260925/ci_replay.py --evidence research/notes/ecc2k130/rotated_s3_fibre_theorem_20260925/evidence/receipt.json`.
The independent `verify.json` was generated by replaying all raw rows with
separate polynomial-product/Euclid field arithmetic and its own S3 formula.
Both producer and verifier returned PASS within the frozen resource caps.
The interpretation and limits are in [RESULT.md](../RESULT.md).
