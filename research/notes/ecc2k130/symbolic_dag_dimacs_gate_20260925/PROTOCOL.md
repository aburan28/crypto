## Hypothesis and deterministic representation

The complete full-point XOR/AND DAG in #802 can be translated by a deterministic, equivalence-preserving Tseitin encoding to ordinary DIMACS CNF. Assign positive one-based DIMACS ID `node_index+1` to each parent DAG node, reject an ID above `2^31-1`, pin node 0 false and node 1 true, and assert the relation output true. In topological node order encode `z=a XOR b` with four 3-literal clauses and `z=a AND b` with three clauses; append fixed-point unit pins in P,Q,R variable order while leaving λ existential. Every line is ASCII, one clause per line, no extended `x` clauses or solver-specific semantics. `write_cnf` computes the exact header count before streaming and stops at the byte cap. A separate parser checks the header, count, literal range and complete assignment; it truth-tables each local gate's clauses independently. Thus a fixed input assignment has one valid auxiliary extension, and that extension satisfies the CNF iff the #802 relation does.

The n2/n3 check exports exactly two base CNFs for moduli `0x7` and `0xb`. For every one of #802's 576 archived ordered canonical PQR rows and all 2,560 λ assignments, independently extend the parent DAG inputs and evaluate the parsed DIMACS clauses; aggregate counts must equal each archived row. Repeat for all 3,264 invalid point-role assignments (off-curve or noncanonical O), all of which must reject. A missing row, local gate truth-table discrepancy, false/true constant drift, malformed DIMACS line, wrong header, or changed parent raw-row SHA fails. The source hash and row SHA of #802 are pinned; no toy domain can be dropped after seeing outcomes.

## Fixed n13 SAT/UNSAT panel

Use only `GF(2^13)` modulus `0x201b` and the twenty explicit `INPUT.json` queries: nine correct full-point additions, nine paired different **on-curve** wrong outputs, a noncanonical O input, and an off-curve affine input. They cover O copy, x=0 self-inverse, ordinary inverse, doubling, distinct-x addition in both operand orders, and high-bit field arithmetic. Several wrong outputs are the other sign with the same x, so an x-only exporter cannot pass. The two independent prefreeze field/group implementations agree on the fixed input-design equations; the solver outcomes are not known or selected. Query order is `INPUT.json` pair order with SAT then wrong-R, followed by the two invalid controls; no adaptive filtering.

For UNSAT, require exit 20 and a nonempty text DRAT proof from `--no-binary`; run the separately compiled, SHA-pinned upstream DRAT-trim source (`2e3b2dc`) on the exact query and proof.
