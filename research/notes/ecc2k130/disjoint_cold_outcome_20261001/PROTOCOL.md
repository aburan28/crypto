The [preregistered protocol](../disjoint_cold_q_20260930/PROTOCOL.md) and frozen Q are unchanged. For every one of the six fixed cells, download the artifact even if its job fails. Preserve preflight logs, build logs, all completed child traces, `cold_run.json`, isolation samples and hosted verifier receipt. Run `verify_cold.py --relocated` on another host for every cell that produced a report; record its receipt and host/tool hashes. A preflight failure or missing artifact remains a censored cell, not an excuse to choose another Q or rerun this protocol. Pack each downloaded artifact once with sorted names, fixed tar metadata and gzip mtime zero; hash the archive and every member. The manifest binds the exact dispatch run, source head, input freeze, hosted receipts and second-host receipts. Keep the raw archive in Git unless a file exceeds the repository limit; in that case, commit deterministic chunks and a reassembly/hash manifest.

`analyze_cold.py` rehashes all sealed member bytes and independently computes the fixed paired CPU ratios from `wait4` user+system CPU. For block `b`, it uses `sqrt(CPU_ic_a,b * CPU_ic_b,b) / CPU_rho,b` and drift `CPU_ic_b,b / CPU_ic_a,b`. It reports the median and two-sided 95% log-ratio t interval across all 20 or five preselected blocks. Eligibility requires every child success, full-rank/scalar replay on both hosts, drift median in [0.9,1.1], drift interval containing one, and zero isolation contention. Failed cells retain raw costs but have no eligible ratio or speed claim. An eligible interval wholly above one is a fixed-policy no-go at that n/L/K, wholly below one is a native-CPU crossover at that cell requiring a separately frozen second-host timing confirmation and common operation-equivalent `S`; an interval touching one is unresolved. Method-level speedup, n83/n131 transfer and challenge DLP remain unset.

The input audit found two distinct n37/L1024 Q pairs in the same signed-Frobenius orbit across blocks: b01 index 218 with b03 index 130, and b01 index 562 with b04 index 973. They are not exact-Q duplicates. Both pairs remain in the fixed sample, and the result must disclose this small dependence. No orbit overlap was found among the n41 or n53 new Q.

The archived outcome is in [RESULT.md](RESULT.md). One frozen verifier failure and the strict isolation gate censor timing in all cells. The `pairing_addendum.py` source was written after that failure and is explicitly a correctness diagnostic, not a post-hoc relaxation of any preregistered performance gate.
