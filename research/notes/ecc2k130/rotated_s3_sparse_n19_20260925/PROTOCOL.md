# Preregistered n19 sparse O-aware prefix-state growth gate

Status: source, input hashes, caps and decision rule frozen before any n19 export or growth outcome. [#786](https://github.com/aburan28/crypto/pull/786) is merged; release requires its preregistered ancestor, final PR head and merge commit to be ancestors of fetched `origin/main`. This is an explicit-state **feasibility and semantic** gate, with no SAT child, solver timing, n131 extrapolation or ECDLP speed claim.

## Fixed input and representation

Use exactly the six beta-3, d=2 rational full-point factor slots in [#767](https://github.com/aburan28/crypto/pull/767)'s committed `raw/n19-m6/factors.json`: GF(2^19) with polynomial `0x80027`, 7 signed points / 4 x values per slot. The 32 exact Q+T labels are #774's fixed n19 Q0..Q7 times T0..T3, in that order; T is `[O,(0,1),(1,0),(1,1)]`, with the point coordinates independently regenerated from #767's eight Q points in the verifier. Add a 33rd O target. The #767 archive, #774 target record, #786 source/evidence and both producer/independent arithmetic source files are SHA-pinned in `FROZEN.json`. No factor point, x, target, field, label or order may be chosen after a growth observation.

The producer uses #781's exact GF(2^n) finite S3 roots and O rule, with x=0 and equal-x degeneracies. It enumerates **reachable** prefix x states S2..S6 from the four x values per slot, then admits O to each prefix group as #781 did, including when not reachable. The final group also admits every frozen target x. It keeps #786's primary group order F0..F5,S2..S6; its Sinz sequential exactly-one blocks use contiguous auxiliary variables after all primary variables. For every stage input pair, emit one clause `(-left,-factor,+allowed outputs...)`; an empty admitted-output intersection is the binary pair ban `(-left,-factor)`. Target assumptions select the final x state or O. Finite target x denotes both rational signs, so exact full target is checked by independent point lifting, never inferred from x alone.

Before building each next state group, write cumulative `growth.json` with stage, reachable/admitted state counts, O status and prospective transition input-pair count. Stop and preserve a **CENSORED** receipt if any admitted state group exceeds 100,000 states, cumulative input pairs exceed 500,000, primary paths exceed 250,000, DIMACS exceeds 20,000,000 bytes, child wall exceeds 180 s exporter / 600 s verifier, or either child reaches 512 MiB in the 50 ms sampled process-group RSS ledger or the direct-child `wait4` peak. The RSS limit is sampled for descendants: a shorter transient peak can escape observation, so a PASS is conditional on this measurement resolution and cannot establish a strict physical-memory ceiling. External child stops are 195/630 s; the runner kills and drains the whole process group before hashing output and records direct-child peak, sampled group peak, wall, CPU and the stop reason. Linux `/proc` and merged-parent checks run before creating the first-attempt directory. No cap can be raised after seeing an outcome in this PR. Record zero/one/two-or-more admitted outputs per stage, all group sizes, exact variable/clause/byte counts, and cold wall/CPU/RSS separately. Do not construct a dense n19 reference CNF.

## Independent semantic replay and controls

The verifier parses every emitted DIMACS clause in order, checks the exact sequential blocks and their one-hot invariant, and derives each local allowed-output set anew from the independent bit-serial/Fermat full-point group law in #767/#762. It does **not** call the producer's root solver or transition predicate. For each parsed pair it checks the admitted-domain intersection, including binary bans and O+factor, equal-x inverse/O, x=0 order-two and nonzero doubling cases. It enumerates every path allowed by the parsed CNF and compares the full ordered path set against the producer's compressed path archive and a separate enumeration of all 117,649 signed factor tuples. The point oracle records every prefix point and exact terminal sign. For all 32 Q+T targets and O, compare full-point signed-tuple counts with #774's complete rational oracle where recorded; check that every CNF target path has a signed witness and that both final signs are handled explicitly. A target with no paths is a complete result only for this finite frozen toy domain.

Five deliberate negative controls must reject: (1) an incomplete x fibre in F0; (2) changing the guaranteed F0 x=0 + F1 x=0 output from O; (3) changing the guaranteed S2=O + F2 x=0 output from finite x=0; (4) changing the guaranteed S3 x=0 + F3 x=0 output from O, and (5) changing the O target assumption to a finite final-state literal. The three altered transition controls operate on parsed clause copies and must fail the independent point-law comparison for the specified pair; their exact original/mutated clauses and rejection class are archived. Any failed control rejects the semantic gate.
