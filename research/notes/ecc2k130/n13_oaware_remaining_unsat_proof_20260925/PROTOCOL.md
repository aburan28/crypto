# Preregistered completion of the fixed n13 O-aware negative certificate matrix

This dependent draft extends [#790](https://github.com/aburan28/crypto/pull/790), head `3f8e052da9265f88dbcf58035c832140b0a0b689`, which independently checked five preselected #785 negative branches. It makes **no new proof outcome claim**. Its first selected proof run is held until #790 merges, this protocol and source are frozen in a draft PR, hash-only CI passes, and pre-outcome peer review reports no blocker. The #790 merge is a manual release gate: pinned source hashes alone do not establish GitHub merge state. This draft deliberately records a null `parent_proof_merge_commit`; after #790 merges, its actual merge commit must be pinned in `INPUT.json`, the source freeze refreshed in a new commit, and exact-head hash-only CI and peer review repeated before any selected proof run. The #790 FROZEN and receipt bytes are dependency-pinned in `INPUT.json`; its source and checker are reused unchanged. The #785 target table, complete panel, CNF schema and base bytes are also hash-pinned by #790's `common.freeze()` and rechecked here.

The target universe is #785's 27 negative Q+T branches minus exactly the five #790 cases Q0T0 and Q4T0..T3. In #785 target order the 22 remaining fixed IDs are Q0T1, Q0T2, Q1T2, Q1T3, Q2T0, Q2T1, Q2T3, Q3T1, Q3T2, Q3T3, Q5T0..T3, Q6T0..T3 and Q7T0..T3. `INPUT.json` fixes each assumption literal and the exact SHA-256 of its #785 one-unit query; the runner rederives each from the base CNF. No branch substitution or target selection after results is allowed.

For each branch, launch one cold, pinned CaDiCaL 3.0.1 child with `--no-binary` and a text DRAT file, then one cold external checker child using #790's vendored upstream DRAT-trim source at commit `2e3b2dc0ecf938addbd779d42877b6ed69d9a985`. An UNSAT branch passes only if CaDiCaL exits 20 and prints UNSAT, the checker exits 0 and prints VERIFIED, query/proof/stream hashes match the receipt, and all caps pass. First failures and partial archives must be kept. Store exact raw proof SHA-256 and bytes, deterministic gzip proof, per-child command, exit, UTC interval, wall/CPU, cumulative child-RSS upper bound and full stdout/stderr bytes. Check proof generation and checker wall separately.

The same non-unit XOR proof must be accepted and its mutant missing essential derived steps rejected by the external checker. After the panel, Q0T1's actual proof must be rejected against #785's fixed SAT Q0T3 query. Replay compiles a fresh checker from pinned source, independently reconstructs every query, verifies every archived proof, and reruns both rejection controls. The Q0T3 control is not a negative target. The first full 22-case panel is the outcome regardless of success or failure; do not replace a failed run with a favorable one.

Frozen per-child caps match #790: 60 s solver, 180 s checker, 1 GiB cumulative child-RSS upper bound, 128 MiB raw proof, 320 MiB temporary workspace, and 512 MiB archived evidence. Runner timeout allows 15 s cleanup grace but the result still fails above the stated wall cap. If a cap fails, retain the partial receipt and proof/streams. No selected proof is generated during hash-only preflight.

A fully checked 22/22 panel, combined with #790's five certificates, would certify all 27 #785 negative **exact CNF branch queries**. Q5, Q6 and Q7 would then be projected-negative in the toy n13,m5 point semantics because each has all four torsion branches checked; Q0..Q3 remain projected-positive via #785's five SAT branches, and Q4 was covered by #790. This is a certificate-pipeline gate only. It does not establish direct S6/S7 semantics, n19/n131 support, relation rank, a challenge logarithm, full index-calculus cost or a rho crossover.
