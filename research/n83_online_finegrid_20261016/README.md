# N83 K3114 fine-grid challenger

For the exact one-root five-byte dynamic index, K3114 is the largest
folded-column count in the 2³⁰-slot bucket. It represents 516,924 expected
usable factor-base points under the current 166-points-per-column policy.
The exact request is 536,569,188 entries and the table has 1,073,741,824
five-byte slots. At K3115 the request is 536,913,860 and the table has
2,147,483,648 slots. The [Lean proof and map](PROOF_MAP.md) establish the
boundary for every larger K under this formula.

K3114 is a follow-up challenger to the ongoing frozen K3072/K2543 mirrored
screen. A future performance comparison must freeze a new source, point,
arm order, resource cap and noise gate before running, then independently
replay each base, exact index and scalar. Its capacity advantage is a
structural reason to test it, not a timing result. The already sealed
five-point Tier 1 panel follows its existing selection protocol.
