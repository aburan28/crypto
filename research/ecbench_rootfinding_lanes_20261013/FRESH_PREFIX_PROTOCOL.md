# Fresh-public-target fixed-prefix confirmation, frozen before target generation

The first [equal-prefix panel](FIXED_PREFIX_INITIAL.md) showed an exploratory stride-23 rank surplus at 4,096 surviving probes, attenuating by 8,192. That panel reused targets from a previously inspected coverage session. This protocol checks the early milestone on eight *new* public targets, with target-generation seed `20261025` fixed in [the workload spec](specs/fixed-prefix-fresh.json) before `ecbench plan --json` is called. The registered curve remains `find_prime_order_curve(20, 59297)`, `r = 562427`. The one-arm ecbench spec is only an input generator; its plan will supply eight target coordinates and algorithm seeds. No scalar values are supplied to the collector.

Freeze the plan, the eight extracted `(x,y,algorithm_seed)` triples, their SHA-256, and a test-source commit before execution. Refuse any target identical to one in the earlier coverage holdout. For each target, generate the batch-8 walk with no oracle relations up to the same 20,000-attempt cap. Require at least 8,192 points that pass the collector's guards, and apply the ordinary, stride-7 and stride-23 B48 pair tables to the exact same first 8,192 points. Rebuild each table cold per target and retain prefix milestones 512, 1,024, 2,048, 4,096 and 8,192; record table hits, independent rank, dependent rows, row operations, group-law field inversions, cold counted GAE lower bound, and structural memory floor. A failed assertion, fewer than 8,192 surviving points, or a curve/target mismatch stays a failed record rather than an altered sample.

*Primary predeclared comparison:* stride 23 minus stride 1 independent rank per target at 4,096 surviving probes, with a paired eight-target bootstrap interval (20,000 resamples, seed `20261025`). The paired rank-per-cold-GAE ratio is a co-primary component-efficiency check; stride 7 is a control. The 8,192-point result and observed/independent-uniform table-hit ratio are secondary. Do not select a different prefix or tune B after seeing this panel. If both primary intervals favor stride 23, the result supports a bounded early-prefix relation-collection effect on this registered curve and these fresh targets; if either spans parity, the prior signal is not confirmed by this gate. Either way, correlated walk probes, native unpriced work, matrix memory and a target-pinned full solve remain separate obligations. A component interval cannot be promoted to a whole-solve speed or ECDLP cost claim.
