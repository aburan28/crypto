# Fixed-prefix coverage addendum, frozen before execution

The five target-pinned ecbench panels use unequal probe budgets. This addendum tests coverage on an equal public stream without changing those sealed sessions. The implementation is `tests/rootfinding_fixed_prefix.rs`; the input binding is coverage-holdout session `ECBS1h1b585c89ebd1`, measured round 1, ordinary B48 arm, `records.jsonl` SHA-256 `8305acc015dc77437df966126bb915bdeae244a1b7c559bc52d7f3413e02601a`. The test pins all eight target coordinates and algorithm seeds from that record. Its curve is `prime_instance_for(20, 59297)`, subgroup order `562427`, target kind public.

For each target, run the *same* batch-8 walk with seed from that record and no oracle relations until 20,000 attempted points. The closure sees only points that pass the collector's identity and repeated-target guards. Retain the first 8,192 surviving points with their exact `(a,b)` coefficients and cumulative walk counters. If any target yields fewer than 8,192, stop with a visible failed test; do not change the prefix or replace its target. No target scalar is supplied to the collector.

Build the ordinary B48 base and fixed x-stride 7 and 23 bases cold for each target. Probe all three negation-folded prime batch pair tables against each target's *identical* 8,192-point prefix. Insert every returned exact relation into an independent incremental matrix, even if its target column pins early. Record hits, independent rank, dependent rows, source-counted group operations and group-law field inversions at prefixes 512, 1,024, 2,048, 4,096 and 8,192. Record unique table keys, exact independent-uniform expectation `2K/(r-1)`, and a structural memory floor. The same stream and fixed prefix remove the unequal-budget stop rule from this coverage comparison; the walk probes remain correlated.

This addendum reports a relation-collection component. Group-law field counts omit factor-base Legendre/square-root work and matrix arithmetic, so they are labeled component counts, not full field totals. Counted GAE is a lower bound that includes cold table construction, the common walk prefix, and the hit checks; record matrix row operations and memory separately. The test output, command, source commit, binary hash, stdout/stderr and a derived JSON receipt are retained. A mismatch, failed assertion or insufficient prefix is an implementation result and is not evidence of a mathematical obstruction. The test does not replace L2 isolation or a full-cost matched rho comparison.
