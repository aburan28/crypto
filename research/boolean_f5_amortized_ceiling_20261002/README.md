# Complete Boolean F5 graded-reuse ceiling

This is a **protocol only**. It will measure an optimistic upper ceiling on
the speedup available from eliminating the matrix build and reduction phases
of the repository's complete Boolean F5 call while leaving criterion work
and returned-polynomial unpacking intact. The registered public synthetic
grid, named F5 route, CPU reservation, source checks, refusal rules and fresh
holdouts are in `PROTOCOL.md` and `protocol.json`.

No producer, timing, gate result, cache implementation, full IC cost or rho
comparison exists. The holdout seeds are unused. This is a conditional
phase-cost screen, not a performance or cryptanalytic claim; no curve or key
input is admitted.
