# Complete Boolean F5 graded-reuse ceiling

This is a **frozen protocol with a native producer; discovery pending**. It will measure an optimistic upper ceiling on
the speedup available from eliminating the matrix build and reduction phases
of the repository's complete Boolean F5 call while leaving criterion work
and returned-polynomial unpacking intact. The registered public synthetic
grid, named F5 route, CPU reservation, source checks, refusal rules and fresh
holdouts are in `PROTOCOL.md` and `protocol.json`.

No qualified timing, gate result, cache implementation, full IC cost or rho
comparison exists. The [pre-measurement route amendment](AMENDMENT.md)
records the inherited direct-pack fallback on sparse support. The holdout
seeds are unused. `run.sh discovery NEW_DIRECTORY`
builds/tests the Rust worker, admits one reserved Linux x86-64 AVX2 core,
runs every frozen cell in a fresh child process, replays the phase accounting
and seals the result without overwriting an earlier attempt. This is a
conditional phase-cost screen, not a performance or cryptanalytic claim; no
curve or key input is admitted.
