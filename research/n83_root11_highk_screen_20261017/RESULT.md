# N83 root11 indexed-slot boundary and K3584 replay

The frozen K3584/root11 arm constructed 594,944 usable factor-base points, solved a full rank-3,584 log system, and recovered all 128 sealed scalars with independent base, four-point relation and phase replay. Its geometric mean target interval was 17.884 ms on the ordinary local host. The earlier K3072/root11 screen measured 16.405 ms on the same public points, yielding a descriptive paired K3584-over-K3072 speedup of 0.917 (95% interval [0.655, 1.284]); K3584 was faster on 62 of 128 points. Mean target probes fell from 58,735 to 51,096, while the packed root table crossed from 5 to 10 GiB and the complete shared-setup process rose from 491.832 to 808.509 s.

The next frozen arm, K4096, exited in 1.463 s with source assertion `one-root complete key bound exceeds fixed indexed slots` before constructing the indexed root search or attempting a target. This is an implementation capacity boundary. For the current `root11_dynamic` flags, the symmetric state bound in `examples/koblitz_orbit_dlp_fast.rs` is `max_states = (83K² + K)/2`; the one-root guard requires `2 max_states < 2³⁰`. The largest integer K satisfying that guard is 3596 (`83·3596² + 3596 = 1,073,294,524 < 1,073,741,824`); K3597 exceeds it. The existing `KIC_INDEXED5_ID30=1` variant selects the wider `2³¹` guard and permits K through 5086 under the same bound. That variant is a separate, explicitly flagged candidate family and requires its own frozen screen and replay.

The exact integer ceilings are kernel-checked in [RootIndexCapacity.lean](RootIndexCapacity.lean), with toolchain `leanprover/lean4:v4.35.0`. `N83RootIndexCapacity.id29_exact_ceiling` proves for every natural K that `83K² + K < 2³⁰` if and only if `K ≤ 3596`; `id30_exact_ceiling` proves the corresponding `2³¹` bound if and only if `K ≤ 5086`. The readable derivation of the source count is `K(K−1)/2 · 83 + K · (⌊83/2⌋+1) = (83K²+K)/2`. The Lean declarations establish the resulting guard bounds; the link from these equations to the Rust branch and flag values is audited against the cited source guard, rather than parsed by Lean. Both `#print axioms` reports list only `propext` and `Quot.sound`. The [proof receipt](proof_receipt.json) gives the command, source digest and checked declarations.
