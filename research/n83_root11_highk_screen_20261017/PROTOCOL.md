# N83 root11 high-K factor-base screen

The final twelve-point Tier 1 panel measured K992, K1107, K1280 and K1024. A separate twenty-four-point Tier 1 comparison of K2543, K2816 and K3072 is already frozen and running. This screen searches four larger root11 factor bases, K3584, K4096, K4608 and K5120, in ascending order on the previously sealed 128-point secondary shared-setup workload. Its role is candidate discovery for a later fresh-point one-target comparison; no point in this workload is used as a confirmatory holdout.

The source SHA-256 is `8a2fe55dd90dc33892c197d27260182bf783fc8212fb485d8297daf2bbba8e12` and the offline release binary SHA-256 is `faaac22aa6228c8d486875d6947fa654417d1122191fbe0eb9bde59bb45eb98f`. The public points have SHA-256 `72486b7d708023838db1104a4a5e75a04b915d6f6d4013057c934fb31000aa87`, and the independent answer sidecar has SHA-256 `3ceee12fb848cc261433f3cd9e7d297f961effede1974e8c95fa25d9bac68720`. The exact root11 environment, runner, verifier, arm order and 1,800-second cap per arm are frozen in `plan.json` before the first run.

Each arm starts in a fresh process with empty caches, constructs all usable factor-base points and the indexed root table, collects a full-rank factor-base log system, and attempts all 128 public points. The runner keeps stdout, stderr, base dump, per-target records, command, hashes, status and wall time in a durable per-arm directory. The independent checker reconstructs the base, verifies the sealed scalar law and all recovered scalars and four-point relations, and checks that the five target phase costs sum to each online interval. A timeout, nonzero exit, missing artifact or failed check remains censored. Stop the ascending screen after the first arm that is not fully replayed, preserving that arm's raw evidence.

For completed arms, compare geometric mean target-online milliseconds and the per-point paired log ratios to K3072 from the preceding screen. The screen is descriptive because the host is an ordinary shared machine and the K3072 baseline was run earlier. Promote a larger-K candidate only after an exact manifest and an independent fresh-point Tier 1 same-point IC/rho holdout. Cold process cost, peak RSS and actual usable point count remain separate criteria; a larger K that improves the target phase may cost more setup.
