# Koblitz structural field panel

Scope: exact arithmetic for n=37,53,83 and both binary Koblitz curves
E_a: y^2+xy=x^3+a*x^2+1, a=0,1. This is a structural survey, not a
decomposition-solver experiment. The earlier GF(8/16/32) controls remain intact.

An exploratory integer recurrence established candidate conductors before this
protocol. This protocol freezes their independent verified replay, not the
original exploration. No random seeds or external compute are used.

Let mu=2*a-1 and tau^2-mu*tau+2=0. Since its discriminant is -7,
Z[tau] is the maximal order O_K. Write tau^n=A+B*tau, so the conductor of
Z[tau^n] in O_K is |B| and trace is 2*A+mu*B. Do not confuse the conductor
of Z[tau^n] with End(E_a), which remains maximal on the original curve.

For odd primes ell != characteristic, the rational ell-volcano depth below
this maximal-order curve is v_ell(|B|). Report all conductor prime factors
and valuations, not a cutoff-filtered list. For a single descending step
the target order has conductor ell and discriminant -7*ell^2. These are
possible orders, not constructed curves or maps.

Validation: compute trace independently by the recurrence t_0=2, t_1=mu,
t_n=mu*t_(n-1)-2*t_(n-2). Check trace equality, Hasse bound, odd trace,
norm A^2+mu*A*B+2*B^2=2^n, and t_n^2-4*2^n=-7*B^2.
Factor conductors by exact trial division; independently check primality of
every factor and multiplication back to the original conductor. For these
odd n, the two curve variants must have opposite traces and equal conductors.
Require every check to pass. Keep source/result hashes and deterministic CI.

No finite-field basis, explicit neighboring j-invariant, kernel polynomial,
isogeny map, rational decomposition, or F4/F5 trace is generated by this
survey. Leave all solver/regularity/end-to-end performance fields null.
The toy exhaustive solver is not parameterized to these larger fields.
