# N83 standard-subspace dimension-18 factor base

This is a typed, content-addressed archive of the dimension-18 standard-polynomial-subspace base on the public N83 Koblitz curve. The archive contains 261,444 unique cofactor-four projected subgroup points, representing 130,722 sign-folded columns. The source subspace has 261,447 curve points before projection and duplicate removal. This representation differs from the 166-point signed-Frobenius-orbit pilot base; its column count, relation probability, and runtime must be measured separately.
