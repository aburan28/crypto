# K=2,048 Frobenius-orbit model construction gate

The retained `a=0`, `public_x_hash`, seed `2026100801` primary base passed one exact, all-affine, five-summand chained-S3 SAT **model construction** on the public fixture-zero target. The worker used the 2,048 signed-Frobenius orbit representatives from the stored 339,968-point object. It imported and validated the replay-bound object and target, then installed **111,478 variables, 1,140,557 CNF clauses and 4,980 native XOR rows**. The measured counts equal the [source-derived admission](../k2048-orbit-domain-admission-20261010/RESULT.md): 892,470 domain clauses and 111,478 required variables. The model has four S3 nodes and 82,668 AND gates. These are construction counts, not equations gained from relation search.

The [worker receipt](run-corrected/worker.json) reports 4,928.33 ms for base import, 2.74 ms for target validation and 64.30 ms for model construction. Its process wall was 5,004.85 ms; the [outer supervisor](run-corrected/outer.json) measured 5,821.53 ms including startup and cleanup. The Linux container had one CPU, a 4 GiB memory cgroup, zero swap, no network, a 180-second outer wall cap, a 150,000-variable cap and a 1,000,000-domain-clause cap. Its cgroup peak was **335,839,232 bytes** (320.28 MiB), and the supervisor verified container removal. The frozen source commit was `0127778e14e6942d36e1223031d4edc99464bcea`; the offline Linux worker build took 148.37 seconds and its binary SHA-256 was `f826e602a09eddefabc28f1697c7d37761b1b4e6e49d42c7fa34982075b9eb0f`.
