# Exploratory n = 61 narrow session

`n61-narrow/` is the first, preregistered shakedown run of the n = 61
step-rate spec. It was measured before the implementation was committed.
Its `session.json` records `git_commit: null` and names a scratch binary
that is no longer retained. The sealed records and original files are
preserved here; this directory is excluded from the frozen comparison
and its timing is not used for a claim.

The replacement session belongs under `../sessions/` with a committed
source revision, a retained binary identity, and a replay receipt.
