## Amendment after the canonical-v2 audit

The first successful implementation run exposed a missing combined control
before publication.  The preregistered statement that two
generator-anchored rows are always necessary after a maximal static kernel is
too strong: one unanchored fixed-target row first couples `d` to the residual
base scale, after which one independent generator-anchored row fixes that
scale.  Two generator-anchored rows are necessary only when no target-coupling
row is already present.

The original protocol remains below for provenance.  The final run adds a
sixth exact system:

```text
complete fixed-target augmented space + one independent generator anchor
```

with expected rank five in the toy control and 165 in the P-256 control.  The
correct surviving requirement is therefore **two independent post-static
equations in total**, comprising either:

1. one target-coupling row and one generator anchor; or
2. two independent generator-anchored target rows.

At least one row must carry a known nonzero generator right-hand side to break
the global scale.  Promotion gate 2 is amended accordingly: require a
non-scalar-labelled P-256 event or complete pipeline that supplies both the
target coupling and the independent scale anchor.  The withdrawn v2 result
and assessment are retained verbatim, and the failed float-comparison receipt
plus successful v2 receipt remain in `isolation.jsonl`.  No v2 result is used
for the final claim.

## Exact scale obstruction

Let the order-`n` group be generated by `G`, let

```text
P_i = [ell_i]G,   Q = [d]G,
```

and write `ell=(ell_1,...,ell_K)`.  Every replayable static homogeneous
factor-base relation `h` obeys

```text
sum_i h_i P_i = O  =>  h dot ell = 0 mod n.
```

Thus every static row lies in `ell^perp`, so its rank is at most `K-1`.
Even a free maximal static relation space leaves the scale of `ell` unknown.

Every unanchored fixed-target decomposition obeys

```text
sum_i c_i P_i = Q  =>  (c,-1) dot (ell,d) = 0 mod n.
```

All such rows lie in `(ell,d)^perp`, so their augmented rank is at most `K`.
They determine at most the projective class of the base and target logs, not
the absolute scalar `d` relative to `G`.

A generator-anchored relation has the form

```text
sum_i c_i P_i + [b]Q = [a]G,
```

with replayable known `a,b`.  Starting from static rank `K-1`, one such row
can raise total rank only to `K`; two independent anchored rows are necessary
to reach rank `K+1` and solve both the residual base scale and `d`.  Supplying
those rows from secret scalar labels is a generic control and receives no
construction credit.

This obstruction applies to all homogeneous static identities, including
nonlinear or non-homomorphic mechanisms used to discover them.  It does not
rule out a structured event that actually emits two independent
generator-anchored rows below rho.

1. exact dependency, projective-census, rank, and group-replay checks with
   zero false positives and false negatives;
2. a non-scalar-labelled P-256 mechanism emitting at least two independent
   generator-anchored rows in one event;
3. a complete relation, decomposition, sparse-linear-algebra, and recovery
   implementation;
4. structured residual degree of regularity at most five;
5. complete cost at or below rho and below `2^120` field/group-equivalent
   operations;
6. cost per usable relation below `2^103`;
7. projected materialized storage below `2^50` bytes; and
8. no discarded probabilistic branch counted as exhaustive.

Attempt no unplanted full-depth P-256 relation unless every gate passes.  A
maximal homogeneous kernel or a scalar-labelled full-rank control is not a
promotion.
