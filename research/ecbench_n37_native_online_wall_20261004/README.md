# Frozen native n37 online wall experiment

Start with the [preregistered protocol](PROTOCOL.md), then the
[result and decision](RESULT.md). `SPEC.json`, `PLAN.json` and `FREEZE.json`
were committed before the [hosted execution](https://github.com/aburan28/crypto/actions/runs/37201442645).
The exact session, independent replay, integrity hashes, machine-readable
decision and a native replay analyzer are committed here. The result is an L1
exploratory diagnostic with no admitted online speedup.

The [committed session](sessions/hosted_ubuntu_01) uses the repository's
standard evidence path. [SHA256SUMS](SHA256SUMS) verifies that path; the
[original artifact manifest](SOURCE-ARTIFACT-SHA256SUMS) preserves the hosted
runner's `session/` layout and the same file content hashes.
