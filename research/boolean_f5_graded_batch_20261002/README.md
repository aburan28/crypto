# Exact graded reuse inside complete Boolean F5 batches

This is a **protocol only** for an actual cached F5 algorithm. Fixed-core
affine batches have already passed structural row-signature tests, and a
separate call-only phase screen found optimistic headroom. Neither result
measures a cached complete F5 call. This experiment requires byte-identical
returned rows, charged cold setup/fallback/destruction, matched native
baseline and candidate in one binary, fresh holdouts, resource-qualified
timing and native replay.

No producer, timing, speedup, full IC cost or rho comparison exists. The
new holdout seeds are unused. Inputs are generated public Boolean systems;
no curve or key interface is admitted.
