# Boolean F5 call-only graded-reuse ceiling

This is a **frozen protocol with passing native discovery and fresh holdout** for a conditional phase-cost screen. It
times the F5 API call and returned-object destruction, with exact output
validation outside those intervals. That boundary corrects the limitation
identified in the prior validation-inclusive study without rewriting its
result or reusing its inspected seeds.

The [source-pinned discovery](DISCOVERY.md) and the disjoint holdout each
passed all four primary optimistic-ceiling feasibility groups, with unchanged
worker/verifier sources and [sealed bundles](CONCLUSION.md). No cache
implementation, measured speedup, full IC cost or rho comparison exists.
`run.sh discovery
NEW_DIRECTORY` runs every fixed public Boolean cell under a reserved Linux
x86-64 AVX2 physical core, validates each returned row set outside the F5
call and destruction timers, and seals its native replay. It refuses to
overwrite an attempt. No curve or key interface is admitted.
