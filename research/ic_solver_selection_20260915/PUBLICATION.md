# Portable PR evidence

The PR includes the accepted and rejected raw query panels, all full-worker outputs,
input fixtures, model, reports, audits, and frozen source snapshots. The independent
audits read these text artifacts directly and require no SQLite campaign files.

`manifest.json` is the original local-run manifest and is preserved as historical
evidence. Generated SQLite databases and lock files are omitted from the PR; their
contents are summarized and certified in the raw reports and can be regenerated by
the frozen workers. The local baseline working-tree patch is also omitted because
it contains unrelated pending work. Its historical hash remains in the manifest.
The shared workspace retains these original files.

`publication-manifest.json` lists the files published by this PR. The research
README uses the copied `parent-OPERATIONS.md` as its parent-contract reference;
the live Rust tournament is a separate research effort and is not part of this PR.
No measured result or frozen runtime source is changed by this packaging.

The isolated PR checkout was tested against current main. `pr-validation/`
retains the additional shared-engine test failure and corrected rerun: 48 tests
passed and one optional native-backend test was skipped. The test now accepts
a bounded unresolved reference result; solver limits and runtime code are unchanged.

Large raw JSON/JSONL artifacts are published as plain UTF-8 `*.parts/part-*.txt`
files. `evidence-parts.json` records their order, original length and SHA-256.
Run `python3 research/ic_solver_selection_20260915/restore_evidence.py` from
the repository root to reconstruct the original files before using the frozen
trainer or audits. Every byte remains reviewable; no content is encrypted or
hidden in a binary archive. `--verify` checks all parts without writing files.
The historical local manifests include their original unfragmented hashes.
