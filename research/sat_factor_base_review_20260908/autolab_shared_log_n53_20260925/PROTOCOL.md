## Ordered gates and ceilings

First run one cold training solve; fail closed if no full rank, replay disagreement, nonzero exit, 360-second timeout, or peak RSS at/above 2 GiB. Then run all three L=32 matched blocks, preserving both arms' raw outputs and any failed/timeout receipts. Each L32 child has a 180-second timeout and 2 GiB RSS gate. Continue to L=128 pilot block 0 only if every L32 arm and independent replay succeeds, all three IC point batches extract 32/32, max L32 IC point wall times four is below 300 seconds, and max L32 RSS is below 1.75 GiB. Pilot L128 child timeout is 300 seconds and 2 GiB RSS. Continue to L128 blocks 1 and 2 only if pilot is complete and independently replayed. Stop the rung on its first failed paired block; never replace a seed. Overall workflow wall ceiling 50 minutes. A stopped rung is a quantified **censored result**, not a favorable omission.
