# Stage 33: charged n=41 public unknown-scalar workflow

Stage 33 advances the missing end-to-end `n=41` gate with five public synthetic targets. The workflow must discover and materialize its factor base, collect and verify relations, solve the sparse factor-base logarithm system, descend all five targets, and run signed-Frobenius Pollard rho on those same points.

The factor-base search is algebraic and target independent. It is limited to the Frobenius union generated by the six public coordinate masks `1,2,4,8,16,32` and its two-torsion saturation. It scores both candidates on 1,024 separately generated subgroup samples without enumerating the 40-bit target subgroup. The five future target points are generated only during the solve stage from domain-separated public hash seeds 41001 through 41005. No target scalar or factor-base logarithm label is supplied to search, collection, or descent.

The exact workflow parameters are frozen in `stage-33-n41-public-unknown-params.json`. The relation solver is direct pair-table decomposition because the matched SAT backend panel is already recorded separately in Phase B; no Groebner basis is used. SAT conflicts are therefore inapplicable to this end-to-end arm and must be reported as such.

The hosted run uses two accounting envelopes:

1. A clean source-bound Rust build records dependency acquisition, parallel build wall and core time, individual child RSS, and sampled aggregate process-tree RSS.
2. The scientific workflow restricts its Python parent and all descendants to one Linux CPU before factor-base discovery. It records true single-core elapsed time, outer core time, process-tree peak RSS, all workflow stage timings, relation counts, sparse-linear-algebra statistics, target descent trials, and rho iterations.

Every recovered factor-base log and target result is certified by group multiplication. The public-target evidence scope must be `public_hash_unknown_scalar`; the older generic `synthetic_known_answer` label is rejected for this run.

This remains a finite public synthetic experiment. It cannot establish a Koblitz index-calculus SOTA result, satisfy the licensed Magma matrix, replace the same-instance SAT/direct/GGMP comparison, or count as unaffiliated reproduction and novelty review.
