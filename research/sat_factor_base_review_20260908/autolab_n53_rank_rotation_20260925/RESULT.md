The two policies used byte-identical new targets and the same point, label and representative arrays **within each base**; the native and certified bases differ and are not cross-base cost controls. The new scalar/point schedule was pinned before outcome and has no scalar overlap with the older 512 training stream or 384 public-Q stream and no point overlap with that public-Q stream. Independent Python field/group arithmetic replayed all 512 relation witnesses per arm and all 23,320 orbit labels; its modular elimination verified the full-rank solutions against all representatives. Both lex arms selected first-pair column 0 on all 512 targets. Each cyclic arm selected it only twice, visited 512 distinct public-target-derived scan starts, and removed the zero-occurrence columns. All four arms had zero failed targets. This is direct evidence that first-relation selection, rather than factor-base membership alone, caused the missing-column rank failure on this held schedule.

The preregistered **native structural-advance gate passes**: native cyclic reached full rank by target 512, had no more failures than native lex, and every relation and base label passed independent replay. Native lex did not reach full rank, so the protocol advances cyclic selection to a separately frozen, fully charged L384 same-Q log-recovery comparison without treating the observed target 273 as a chosen training cutoff. The fixed 512-target native cyclic process wall was 6.246 s below native lex; certified cyclic was 3.244 s above certified lex. These are descriptive single-process differences in a fixed four-arm order, not a runtime confidence interval or an attack-speed claim. The certified fixture was decompressed once before the children (9.833 ms, reported separately); each certified child charged its own loading, while each native child charged fresh base construction. The within-base policy comparisons are the primary controls.

This arithmetic mixes different runs, target streams and bases; it is **not** a measured bound or comparison.
