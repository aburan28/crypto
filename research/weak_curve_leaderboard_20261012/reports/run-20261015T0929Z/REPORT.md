The [native receipt](../../ghs_genus128_cost_audit.json) records both `c2pnb176w1` and `c2pnb272w1` by exact curve ID and subgroup order. The graph uses [plot.py](plot.py) to render only recorded prices; no measured runtime or uncertainty interval is attached to this cost model.

The local [six-test log](catalog_tests.log), [snapshot check](snapshot_check.log), and [audit check](audit_check.log) are retained.
