What the paper shows [derived]

  • Thin product (Thm 1 / Thm 5). X: N x D, Y: D x N, D ≤ N^(1/18), |W| ≤ N^2/sqrt(D) wanted positions: all (XY)[i,j] for (i,j) in W in O(N^2/D^0.063) operations — polynomially less than one operation per entry of the full product. General form: for every ε < 0.1204, κ > 0 there is γ > 0 with O(N^2/D^γ) when D ≤ N^ε, |W| ≤ N^2/D^κ.
  • Technique. Schoenhage's 10-multiplication identity inside a Coppersmith-style recursion, visiting only the recursion-tree leaves the wanted entries need; encoding work is shared across blocks.
  • Graph reading. With X, Y as biadjacency matrices this is the counting Lopsided All-Edges Sparse Triangle: (XY)[a,b] counts middle vertices adjacent to both outer vertices a, b. Cost for ε < 1/18: O(|W| n^(0.437 ε) + n^(2-0.063 ε)).
  • Data structure (Thm 3). Preprocess (X,Y) in O(N^2/D^0.063), answer any single entry in O(D^0.437).
  • Reductions. 3SUM / Exact Triangle / APSP reduce to the lopsided problem, giving O(n^1.9992) 3SUM and O(n^2.9995) APSP. SETH / Orthogonal Vectors are explicitly unaffected.
