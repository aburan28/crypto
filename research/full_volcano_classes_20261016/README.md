## Completed correctness runs

The native release tests include an independent exhaustive census of every
nonsingular model over each small field, compared against the complete vertex
set generated by isogenies. They also exercise a maximal-order class number of
three, resume/uninterrupted equivalence, map tampering, incomplete degree sets,
supplied-order/domain checks and a verified BSGS solve with negative controls.
Two process-level controls additionally kill a live writer after a committed
expansion, recover and resume the database, compare every vertex/edge against an
uninterrupted run, and check that invalid/existing outputs are never overwritten.

## Run the command

See [the CLI contract](../../tools/volcano-cli/README.md) for limits, file schema,
exceptional cases and all options.

```sh
cargo build --release --locked --manifest-path tools/volcano-cli/Cargo.toml
tools/volcano-cli/target/release/isogeny-class plan \
  --curve research/full_volcano_classes_20261016/inputs/A.json
tools/volcano-cli/target/release/isogeny-class build \
  --curve research/full_volcano_classes_20261016/inputs/A.json \
  --out /durable-volume/A.sqlite --steps all
tools/volcano-cli/target/release/isogeny-class resume \
  --input /durable-volume/A.sqlite --steps all
tools/volcano-cli/target/release/isogeny-class verify \
  --input /durable-volume/A.sqlite
```

The same API is exposed by `crypto isogeny class` and `isogeny class`. A finite
degree set is explicit; `--degrees 2,3,5` includes additional prime-degree maps
while keeping vertex completeness separate. Each outgoing kernel is retained,
including loops and parallel kernels. Arbitrary-degree maps are an infinite family.

## Historical complete dataset

The complete historical B archive has all 129,140,163 vertices, 18 strata and
258,280,326 directed degree-3 kernel maps. Its raw/compressed hashes, byte counts,
audits, canonical 79-part Drive index and reconstruction notes are under
[`evidence/historical-B/`](evidence/historical-B/README.md).
The graph bytes are separately distributed and preserved. These are archival
pre-repository results, not newly admitted ecbench timing evidence.

  conductor labeling for every vertex.
- Any enlarged finite degree set beyond the preserved historical B degree-3
  graph, exhaustively expanded at every vertex.
- The full matched rho/BSGS/PH, direct elliptic-curve factor-base IC and applicable
  finite-field-reduction IC campaign, with all requested targets, complete

The new solve command verifies one explicit cyclic-subgroup BSGS target. It does
not discharge that graph-wide experiment. Reusing the established class-number
and volcano theorems is not a new mathematical result; no new Lean proof is claimed.

Canonical IC/rho scoreboard, progress timeline and performance-gain graphs retain
their measurement values: this change reports no new comparison. The registry,
roster views and derived cover/browser metadata are refreshed for the eight
registered source models. Metadata import is native and isolated from research
crate JSON features: `tools/volcano-cli/metadata-import/` reads only frozen plans;
it does not count points or invent subgroup representations.
