# Backend and algorithm frontier

A curated, reproducible view of frozen F4, F5, F6-IC, root-finding, SAT and reference sessions. Observations stay separate by exact target, configuration, binary and host. This imports historical evidence without rerunning a solver; it is not an exhaustive or globally fastest claim. The IC recipe leaderboard remains the source for admitted whole-pipeline comparisons outside these sessions.

observed single-target, cold solve count-band frontiers within one session and exact workload; not ledger promotions, global records, or cross-host wall rankings

Generated by the native `backend-leaderboard` tool. Each row is one exact target, backend configuration and session. Field degree m, field size 2^m and subgroup order r are separate. Unknown costs remain unknown.

Reproduction: [acceptance criteria](REPRODUCING.md), [exact per-session command cards](REPLAY_PLAN.json), and [pinned input/output hashes](reproduction.lock.json). Report-byte reproduction is separate from fresh algorithm/solver-ledger reproduction and statistical timing replication. No fresh run is asserted by generating this report.

Cold solve ms includes the method's setup, search, extraction and internal verification. Process ms is fork-to-reap and includes startup. The runner's independent scalar check is outside both clocks. Online ms excludes reusable setup. All clocks are descriptive unless a same-target L2-or-higher paired comparison passes its A/A and 95% interval gates.
