## Question and decision

Does a crater/floor CPU difference survive randomized interleaving on the same reserved worker?

A balanced crossover separates endpoint effects from the scheduling waves in the completed campaign. If CPU differences disappear while query counts remain comparable, prioritize systems controls rather than conductor-based hardness explanations.

## Design to freeze

Use 20 frozen existing gaps, four fresh targets per gap and three IC arms: crater CM, the same crater recurrence, and floor recurrence (240 attempts). Randomize the six possible arm orders across blocks; use fresh processes, one active worker, a fixed resource reservation and local contention receipts. Use matched public seed labels, but do not claim geometrically identical points on different curves. Log full cold process CPU, orbit/table/collection CPU, queries, failures and replay separately. Compare crater CM versus recurrence on identical points before comparing endpoints. Bootstrap whole gaps, retaining all targets. Pre-register an equivalence margin only after deciding what practical effect matters; a confidence interval containing one does not establish equivalence.
