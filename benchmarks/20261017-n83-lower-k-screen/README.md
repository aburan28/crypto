# N83 lower-K factor-base screen

The [graph](screen.svg), [PNG](screen.png) and [PDF](screen.pdf) show eight
current-source root11 base sizes on one previously exposed N83 point. K992

with 164,672 usable base points and 992 folded columns. Every run passed
independent base, relation, scalar and phase replay. These shared-host L0
measurements nominate K992 for the [sealed ten-point Tier 1 follow-up](../../research/n83_k992_cold_followup_20261017/PROTOCOL.md).
