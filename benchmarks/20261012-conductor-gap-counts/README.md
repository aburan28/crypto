# Conductor-gap counted-work diagnostic

The source of truth is
[the study](../../research/ecbench_conductor_gap_20261012/README.md).
PDFs and SVGs are byte-identical copies of the inspected study reports and
graphs. PNGs are 150-dpi raster renders of those same SVGs. The plotted
observations come from the native analyzer; this gallery computes no new
measurement or statistical comparison.

All 192 executions verified; all 96 measured executions replayed exactly.
Both 99% IC floor/crater intervals include one. Native costs are partly
unpriced, wall isolation is L0, and the dataset contains two fixed curve pairs.
No complete-cost, scaling or cryptographic hardness claim is made.
