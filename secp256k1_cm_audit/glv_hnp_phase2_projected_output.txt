EXP P5: BDD formulation — L0 = {v in Lbar : Kannan coord 0}, rank 2m
------------------------------------------------------------------------------
P1 shows the shortest vector of Lbar still has Kannan coordinate 0, so
recovery is BDD with target distance pv in the rank-2m lattice L0.
L0 splits into m identical 2-D lambda blocks <(n*S_K1,0),(-lam*S_K1,S_K2)>
plus the (long) P-row, so lambda_1(L0) should equal the exact 2-D block
shortest vector mu.  Unique BDD decoding needs pv < lambda_1(L0)/2,
i.e. rho = mu/pv > 2.  This is the controlled test T2 could not make:
same n-size, same K2, same m, ONLY lam and K1 vary.

EXP P7: (a) enlarge the controlled slice; (b) document the sign flip
------------------------------------------------------------------------------

That is the OPPOSITE direction to H20 (2026-07-29), which predicted
large rho = mu/pv = success and was falsified.  10 points can be luck,
so (a) re-runs the slice on ~30 fresh curves.  (b) contrasts it with the
within-curve K1 sweep, where the direction is reversed.
nu = mu/n is the scale-free form: mu = n * min_(a,b) sqrt((a/K1)^2+(b/K2)^2)
over a = -lam*b mod n, so nu is directly comparable across K1 and n.
