E8: does dist/GH predict the residual V2 wall?
------------------------------------------------------------------------------
E7(c) shows K1=12 needs only m_min=6 signatures, yet V2 with m=32
still fails there — so the residual wall is NOT information-theoretic.
Test the lattice-geometry explanation instead.  For the V2 lattice L2
(rank 2m) the determinant is exactly
      det(L2) = S_K1^m * n^(m-1) * S_K2^m        (verified symbolically)
so the Gaussian heuristic is GH = det^(1/2m) * sqrt(2m/(2*pi*e)) and the
BDD target distance is ||(k1_i*S_K1, k2_i*S_K2)|| ~ n*sqrt(2m/3).
Closed form:  dist/GH ~ sqrt(2*pi*e/3) * sqrt(K1*K2/n) * n^(1/2m).
