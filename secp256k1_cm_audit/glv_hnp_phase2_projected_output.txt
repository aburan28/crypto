EXP P6: what DOES set the wall?  Gaussian-heuristic ratio of lattice B.
------------------------------------------------------------------------------
det(B) = (n*S_K1)^m * S_K2^m * S_KAN / n = n^(2m) / eff^m,  N = 2m+1
GH(B)  = sqrt(N/(2*pi*e)) * det^(1/N)
||pv|| = n * sqrt(2m/3 + 1)   (k1,k2 uniform; d is gone in B)
R = ||pv|| / GH(B).  R < 1 => planted vector is below the heuristic
lambda_1 and unique-SVP/BDD is plausible; R >> 1 => it is not.
