EXP E6: is the K1 wall information-theoretic?
------------------------------------------------------------------------------
Counting argument.  Candidates for (d, k2_1..k2_m) number n * K2^m; each
forces k1_i = A_i + B_i d - lam k2_i mod n to land in [0,K1), which for a
random candidate happens with probability (K1/n)^m.  Expected number of
spurious solutions is therefore
    N_spur = n * (K1*K2/n)^m = n * eff^m,
so the solution is information-theoretically unique iff
    m * log2(1/eff) > log2(n)      [surplus = LHS - RHS, in bits].
If the observed wall sits at a K1 where the surplus is still large and
positive, the wall is NOT information-theoretic.

EXP E8: Bleichenbacher bias of the GLV nonce -- the complementary method
------------------------------------------------------------------------------
E6/E7 show the leak is only log2(1/eff) = log2(sqrt(n)/K1) ~ 2.7 bits per
signature and that the lattice loses ground as 1/sqrt(m).  The classical
remedy in the few-bits regime is Bleichenbacher's FFT/bias method, which
needs no lattice at all.  Its figure of merit is the nonce bias
    B(K) = E[exp(2*pi*i*k/n)],  k = k1 + lam*k2 mod n.
Because k1 and k2 are independent this factors exactly:
    B = D(1, K1) * D(lam, K2),   D(c,K) = (1/K) * sum_{j<K} e^{2pi i c j/n}
             |D(c,K)| = |sin(pi*c*K/n)| / (K*|sin(pi*c/n)|).
The ENVELOPE of |D(lam,K2)| is 1/(K2*sin(pi*lam*)), which grows as
lam* -> 0 -- exactly the regime where the lattice attack dies.  That
suggests an anti-correlation; E9 tests it and refutes it.

CAUTION: |B| is NOT monotone in lam*.  Only its ENVELOPE
1/(K2*sin(pi*lam*)) decreases; the numerator |sin(pi*lam**K2)| oscillates
with period ~1/K2 in lam*, so |B| has near-zeros (see lam*=0.25 above,
|B|=0.0004).  The three historical curves happen to line up with the
anti-correlation (|B| = 0.0021 / 0.0186 / 0.0805 against LLL 5/5, 5/5,
0/5), but that is 3 points against an oscillating function -- exactly the
shape of the lam/n error made on 2026-07-26.  E9 tests it properly.
