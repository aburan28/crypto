EXP E6: is L_dfree exactly the quotient L_orig / <n*S_D*e_m> ?
------------------------------------------------------------------------------
Prediction from the construction:
    det(L_orig) = (n*S_K1)^m * S_D * S_K2^m * S_KAN
    det(L_free) = (n*S_K1)^(m-1) * S_K1 * S_K2^m * S_KAN
  => det(L_orig)/det(L_free) = n*S_D = ||trivial vector|| exactly,
  and dim drops by exactly 1.  If so the two lattices have the SAME
  geometry once the trivial direction is projected out, which would
  explain E5's 0/300 disagreements structurally rather than by luck.

curve                dim o/f  det ratio  pi(L_o) subset L_f  L_f subset pi(L_o)
8-bit/199            14/13         True                True                True
12-bit/2557          18/17         True                True                True
12-bit/2677 FAIL     22/21         True                True                True

  E6 verdict: PASS — L_free = pi(L_orig) EXACTLY.
  The d-free lattice is not a new lattice: it is the original with the
  trivial direction n*S_D*e_m projected out.  Recovery is therefore the
  same BDD problem in both, which explains E5's 0/300 disagreements
  structurally.  The d-column costs LLL one wasted dimension and nothing
  else; removing it cannot move the wall.
