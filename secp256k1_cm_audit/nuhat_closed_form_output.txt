D. EXACT NULL LAW for nu_hat over random lam
==============================================================================
   normalising u = q/R, w = theta*R/n gives nu_hat^2 = min(u^2 + w^2)
   with u*w = q*theta/n: L2/sqrt(det) is a unimodular 2-lattice, so
   under equidistribution nu_hat^2 = 1/Im(tau), tau ~ Haar on SL(2,Z)\H.

   derived CDF:  P(nu<=r) = 3r^2/pi                        (r <= 1)
                          = (3/pi)[r^2 - 2r^2*sqrt(1-r^-4)
                                   - 2*asin(r^-2) + pi]    (1 <= r <= (4/3)^(1/4))
   support ceiling = Hermite bound (4/3)^(1/4) = 1.074570

H. THEOREM: an unconditional floor on nu_hat for GLV (j=0) curves
==============================================================================
   a + b*lam = 0 (mod n)  =>  a^2 - ab + b^2 = 0 (mod n)  =>  >= n,
   so nu_hat >= sqrt(t_min/(S1*S2)),  t_min = smaller root of
   (3/4)t^2 - (S1^2+S2^2)t + S1^2*S2^2 = 0.   No lattice reduction,
   no heuristics, no CM hypotheses -- just positive definiteness.
