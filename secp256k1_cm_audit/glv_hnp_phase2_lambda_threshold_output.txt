EXP T1: representation invariance of the lattice under lam -> lam - n
------------------------------------------------------------------------------
The Phase-2 lattice contains the rows n*S_K1*e_i, so replacing lam by
lam - n is a unimodular row operation: SAME lattice, SAME planted vector.
If lam/n were causal, 0.07 vs -0.93 would behave differently.

curve                 lam/n  (lam-n)/n  LLL(lam)  LLL(lam-n)  HNF equal
8-bit/199            0.5327    -0.4673       5/5         5/5       True
12-bit/2557          0.6600    -0.3400       5/5         5/5       True
12-bit/2677 FAIL     0.0699    -0.9301       0/5         0/5       True

Also: the two roots of x^2+x+1 mod n are lam and n-1-lam, so
lam* = min(lam, n-lam)/n is the SAME for both roots — any genuine
predictor must be a function of lam*, not of lam/n.
