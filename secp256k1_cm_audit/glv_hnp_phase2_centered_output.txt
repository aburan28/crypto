C5: optimal S_KANNAN = t*n, and the wall with the fully tuned lattice
------------------------------------------------------------------------------
Minimising r(t) = sqrt(C + (t*n)^2) / (const * (t*n)^(1/dim)) over t gives
t*^2*n^2 = C/(dim-1) with C = m*(E[k1^2]*S_K1^2 + E[k2^2]*S_K2^2) + n^2/3.
Centred, large m:  C -> n^2*(m/6 + 1/3), dim-1 = 2m+1, so t* -> 1/sqrt(12)
= 0.289.  The 2026-07-26 builder uses t = 1.0.
