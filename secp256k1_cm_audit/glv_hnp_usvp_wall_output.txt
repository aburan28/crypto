T23-D  extrapolation of the floor to cryptographic size
==============================================================================

H2 floor:   nu_inf(r) = 2.3860 * sqrt(r),   r = K1*K2/n.
No number of signatures can push nu below nu_inf, so the attack is capped at

    r  <  r_floor = (NU_CRIT / 2.3860)^2 = 0.3120
    log2(K1) + log2(K2)  <  log2(n) - 1.68

i.e. the two GLV nonce halves together must lose ~1.7 bits
relative to the modulus, independent of how many signatures are collected.

  n ~ 2^20    K2 = sqrt(n) = 2^10.0   => K1 < 2^8.32  (k1 must be 1.68 bits short of sqrt(n))
  n ~ 2^64    K2 = sqrt(n) = 2^32.0   => K1 < 2^30.32  (k1 must be 1.68 bits short of sqrt(n))
  n ~ 2^128   K2 = sqrt(n) = 2^64.0   => K1 < 2^62.32  (k1 must be 1.68 bits short of sqrt(n))
  n ~ 2^256   K2 = sqrt(n) = 2^128.0  => K1 < 2^126.32  (k1 must be 1.68 bits short of sqrt(n))
